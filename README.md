# MelonClaw

MelonClaw 是基于 Deep Agents 的通用 AI 助手，在浏览器中完成研究、写作、文件处理和多步骤任务。你可以上传资料、提出任务，在同一个界面查看执行过程、确认敏感操作，并预览或下载生成的文件。

## 核心能力

- **研究与写作**：结合资料和工具完成多步骤任务，通过 Skill 复用任务方法，通过 MCP 连接外部服务。
- **文件处理与交付**：上传附件，在聊天中生成文件，直接预览 HTML、Markdown 等内容并下载结果。
- **项目与长期记忆**：同一项目下的多个会话共享工作区文件，长期记忆帮助跨会话保留信息。
- **可查看、可确认的执行过程**：查看工具调用与任务进展，在需要审批的操作前确认或拒绝。

## 本地快速启动

### 1. 准备环境

- Python 3.11+（低于 4.0）与 [uv](https://docs.astral.sh/uv/)。
- Node.js 20+ 与 npm。
- PostgreSQL 14+：已启动，应用账号可连接数据库并建表。
- macOS / Linux（Windows 可用 WSL）；一键脚本需要 Bash、`curl`、`lsof`。

在项目根目录执行：

```bash
# 已有 .env 时保留原文件，不要覆盖
cp .env.example .env
uv sync --locked
npm --prefix frontend ci
```

### 2. 配置数据库

编辑根目录 `.env`，**首次启动唯一必填项是 `DATABASE_URL`**：

```dotenv
DATABASE_URL=postgresql+asyncpg://<用户>:<密码>@<主机>:<端口>/<数据库名>
```

替换为自己的 PostgreSQL 连接信息，数据库须提前创建。其他变量可保持默认；连接串格式、持久目录和可选配置见[配置与手动启动](docs/configuration.md)。不要提交 `.env` 或公开实际凭据。

模型在启动后的页面配置；首次启动无需配置 Tavily 或 MCP。

运行已安装的 DM Skill 脚本时，还需配置 DM 凭据、共享客户端目录及 Shell 变量白名单；路径插值使用 `${HOME}`。见 [DM Skill 的 Shell 配置](docs/configuration.md#dm-skill-的-shell-配置)。

### 3. 首次初始化

```bash
uv run melonclaw-resources --service-stopped install-builtins --source .data/skills/shared
uv run melonclaw-db-init
```

以上命令安装内置 Skill 并初始化数据库，创建管理员 `admin`（初始密码 `admin`）。不会自动清库或覆盖已有 Skill；模型需在页面配置。

### 4. 启动前后端

一键启动：

```bash
scripts/start.sh
```

访问前端 [http://127.0.0.1:8001](http://127.0.0.1:8001)，后端默认地址为 [http://127.0.0.1:8000](http://127.0.0.1:8000)。一键脚本默认使用 `dev`，读取 `.env` 并开启开发身份切换，仅用于本机开发。

### 5. 配置模型并开始聊天

1. 用 `admin` / `admin` 登录后修改密码。
2. 点击左侧四块图案、右上方块呈菱形的「拓展」图标，在「模型」配置供应商地址和 Key，启用供应商，再添加并启用支持工具调用的模型。
3. 新建对话、选择模型并发送消息，收到回复即完成基本验证。

未配置模型时可以管理配置，但不能聊天。之后可以尝试上传一份资料，请助手总结内容并生成 Markdown 文件。

每条用户消息、每个 Agent 默认最多调用模型 200 次、工具 500 次，可在环境配置中通过 `MELONCLAW_AGENT_MODEL_CALL_LIMIT`、`MELONCLAW_AGENT_TOOL_CALL_LIMIT` 调整，重启 Web 后生效。已有环境文件中的显式值优先于默认值。取数指引要求同一数据项、同一目标范围最多尝试两次，仍失败或为空则注明日期、来源与缺失原因并继续完成可交付部分；该规则由提示词引导，硬上限仍会终止超额执行。详见[Agent 运行控制](docs/design-docs/agent-runtime-controls.md)。

## 停止与更新

```bash
scripts/shutdown.sh           # 停止一键脚本启动的前后端
scripts/restart.sh            # 重启前后端
```

生产服务器更新代码后运行 `uv sync --locked --default-index https://pypi.org/simple` 和 `npm --prefix frontend ci`。已有数据库需要升级时，停服后执行 `uv run melonclaw-db-update`，再重启；该命令保留业务数据，首次建库才用 `melonclaw-db-init`。Linux 标准部署会自动读取 `/etc/melonclaw/melonclaw.env`；其他外部配置路径先设置 `MELONCLAW_ENV_FILE=/配置文件路径`。服务启动不会自动建表或升级。本地开发直接运行 `uv sync --locked`。

## 使用边界

当前适合本机开发与个人使用。`LocalShellBackend` 不是安全沙箱，人工审批不能替代系统隔离；不要向不可信用户开放宿主机执行能力。

## 定时任务

可以在普通会话直接说“每天早上九点写一集小说，共三十集”，AI 会提取要求并保存任务，当前会话就是它的固定会话。后续说“改成晚上八点，文风轻松一点”“暂停任务”或“恢复任务”即可修改本会话的任务；未提及的配置保留。必要信息缺失时会追问，成功后告知实际配置和下次执行时间。创建时未指定执行模型则使用管理员设置的系统默认模型，编辑时未指定模型则保留原模型；系统默认未设置或不可用时会提示配置或通过问题卡让你明确选择可用模型，回答后才保存任务；只讨论方案或追问报告不会要求修改配置。项目会话不支持任务配置，一个会话只对应一个任务。

也可从全局导航“定时任务”新建任务，填写名称、要求、明确模型和执行计划。闹钟图标选中时显示黑色圆盘与白色指针。支持手动、指定时间一次、每天或每周，全部使用北京时间、分钟精度，不支持每小时、每月等其他频率。表单“保存”等待计划触发，“保存并运行”额外立即执行一次；聊天保存等待计划触发。表单创建和修改定义时记录用户设置摘要，聊天使用真实用户消息；每次触发仅追加一条 AI 消息，在同一条消息中更新状态和 Markdown 结果。任务会读取本任务累计历史继续执行，例如每天接着写一集小说。关闭页面不影响后台执行，定时任务保留配置和运行记录入口。

任务支持编辑、暂停/恢复、归档、取消和按当前配置重新运行。暂停仅停止后续计划，已有运行继续；恢复只安排未来周期，错过的计划不补跑，上一轮未结束则跳过本次。归档前的确认框展示任务名称及影响，默认聚焦“取消”，点击“确认归档”后才执行。归档保留历史、取消排队记录，已经开始的运行继续完成。执行中取消要等后台确认停止；已发出的远端请求可能仍在处理。

任务列表展示任务名称、任务模型、执行计划（频率、每周计划的星期、运行时间）、状态、最近一次运行和下一次运行，时间统一为北京时间；保留“查看会话、运行、编辑、归档、暂停/恢复”五个操作。

历史过长时会复用摘要并保留近期正文，历史准备默认最多 60 秒、摘要最多 4 次；超时或超预算明确报错，可重试或选择更大窗口模型。后台完整运行默认限时 30 分钟，包含历史准备；结果未变化时不重复保存。任务改名会同步默认会话标题，自定义标题保留；保存按钮分别反馈当前动作，不同任务可独立操作。完整操作回执默认保留 30 天，过期重试会要求先核实当前状态，旧请求不会再次执行。参数见[配置说明](docs/configuration.md)。

已有任务中心升级本版本时，先等待活动运行结束并停止 Web，再执行 `uv run melonclaw-db-update`，随后启动服务；升级保留任务、运行结果和聊天。Linux 标准部署自动读取 `/etc/melonclaw/melonclaw.env`；使用其他路径时先设置 `MELONCLAW_ENV_FILE`。首次空库仍执行 `uv run melonclaw-db-init`，服务启动不会自动升级。

状态颜色：启用/成功为绿色，暂停为橙色，排队/执行中为蓝色，失败为红色，归档/取消为灰色。

点击任务名称直接打开固定会话；点击“最近一次运行”中的状态/时间打开运行记录抽屉，查看全部历史、执行当时的模型/配置版本/任务要求、计划与实际起止时间和失败原因。排队或执行中的记录可取消当次运行，后续计划仍保持原状。关闭抽屉保留列表筛选和页码，保存配置后留在列表，“保存并运行”打开会话。

对话配置和定时任务表单使用相同保存规则，修改影响后续运行，已开始的运行保持原配置。“查看会话”和运行后的跳转打开任务的固定会话；每次执行依次追加，同一会话可以直接追问，模型读取本轮绑定的累计历史。任务结果按普通 AI 回复展示，不显示任务名、触发时间或配置/引用按钮；可直接追问具体日期或某次报告，模型使用累计历史和原文读取工具。任务配置与取消在定时任务操作，也可通过对话修改配置。全局导航不再提供独立任务通知入口，结果直接在对应会话阅读。任务会话不能移入项目，先归档任务并结束运行后才可删除会话。

页面可见且应用就绪时，侧栏每 30 秒刷新最多 100 条任务会话摘要，由后端直接筛选任务会话；不会定期遍历全部分页或读取普通会话的消息正文。后台刷新与“加载更多”按会话 ID 去重。当前打开的任务会话仍每 3 秒同步新增消息和未完成消息；页面隐藏时暂停，恢复可见后立即同步。未打开会话的任务结果保存在历史记录中。

当前任务只生成文字、使用已授权公开搜索、受限子任务和本任务历史，不读取其他会话、项目文件、Memory 或 MCP，不执行 Shell 或自动批准工具。任务不关联项目或 Skill；没有模型时先到“拓展 → 模型”配置。

已有应用首次接入定时任务时，停服后执行数据库更新：

```bash
scripts/shutdown.sh
uv sync --locked
uv run melonclaw-db-update
scripts/start.sh
```

首次安装使用 `uv run melonclaw-db-init`，已有应用通过 `20261010_task_center` 一次创建当前完整三表。Web 不自动建表或升级。当前结构无需清库；未发布的旧任务结构不提供迁移，需停服后重建任务相关表，保留账户、模型和普通聊天。初始化命令不会清库，清空记录也不能修复表结构差异。

任务调度由 Web 内置 APScheduler 自动启动，不需要额外命令或进程。默认每 2 秒扫描计划和排队记录，全局并发 2、每用户 1、最长排队 24 小时。只支持单实例 Web：同一数据库的第二个任务执行器会被拒绝，不能使用多进程 Web 或滚动重叠启动。任务随 Web 停止，正常停服记为 service_shutdown；异常退出后的运行由下次启动标记 service_restarted，保留部分结果，不自动重跑。

`GET /api/ready` 同时检查 Web 与内置执行器就绪；登录后的 `/api/tasks/status` 返回 executor 状态、运行数和最近扫描时间。start/restart/shutdown 脚本只管理前端和 Web，frontend 参数只处理前端。

任务只使用 tasks、task_runs、task_operations 三张表；会话消息复用现有聊天表。Linux 运维见[部署说明](docs/deployment.md#定时任务上线与运维)。

已使用当前三表结构的应用接入对话配置时，只需重启 Web 并刷新页面，无需改表、清空历史或重新初始化数据库。

历史消息保留真实角色和顺序，发送模型前合并相邻同角色的普通文本；工具调用保留协议。历史过长时使用早期摘要和近期原文，可按需读取旧章节。失败/取消不计完成，有限目标全部完成后由后台明确结束并暂停后续计划；修改任务后，旧执行不能暂停新配置。

计划固定容纳 60 秒正常轮询延迟；超出则跳过，不补跑。完成超过 30 天的任务 Checkpoint 每小时定向清理，报告和未读状态保留。限额见[配置参考](docs/configuration.md)，API 与边界见[设计](docs/design-docs/task-center.md)和[验收](docs/design-docs/task-center-acceptance.md)。

定时任务列表与运行记录的状态使用 14px 圆角胶囊：启用/成功为绿色，排队/执行为蓝色，暂停为橙色，失败为红色，归档/取消为灰色；边框、浅底色与文字颜色同步区分。

定时任务列表按已启用、已暂停、已归档排序，同状态内按最近更新时间降序；排序在服务端分页前完成。列表使用留白更充分的行、浅色表头与圆角边框；运行按钮使用浅蓝强调，其他操作使用文字按钮，归档使用红色。窄屏可横向滚动查看全部列。

定时任务列表压缩列宽，1477px 窗口下无需横向滚动；最近一次运行的日期与时间同一行、下一次运行分行，均显示到分钟，一次性计划的类型与日期时间分行，列表不重复标注北京时间（仍按北京时间显示）。

已启用且工具白名单允许的外部 MCP 工具直接调用，不逐次人工审批，也不通过 `ask_user` 请求调用批准；缺少关键任务信息时仍会提问。请通过服务启用状态、工具白名单和远端凭据限制调用范围。聊天安装、测试 MCP 配置仍保留审批。

聊天安装 MCP 时，一条消息中的 `mcpServers` 支持 1–20 个服务。管理员安装为系统共享，普通用户安装为个人配置；审批卡展示安装范围，共享启用影响所有用户。

### 首页研究引导

首页研究引导分为「权益 / 固收」两个 TAB，每次只展示一组，默认权益，每 8 秒自动交替激活；鼠标悬停、键盘焦点位于引导区或页面隐藏时暂停，离开后重新计时。两个 TAB 首张均为「了解助手能力」，各展示 12 张卡片，宽屏为 3 行 4 列：「了解助手能力」随当前 TAB 使用相同配色，CICC/HTSC 权益研究为浅蓝卡片，DM 固收研究为浅青绿卡片。固收入口覆盖债市日报、资金面、主体信用、机构行为、债券行情与发行、国债期货、境外债券、收益率曲线、信用利差和债券到期。点击后提示词填入输入框，可补充公司、债券代码或日期再发送。数据与产物依赖当前启用的 MCP、Skill、订阅权限及运行依赖；缺失数据应明确说明。
