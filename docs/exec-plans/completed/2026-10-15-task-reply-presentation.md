# 任务回复与列表展示简化

状态：已完成
开始日期：2026-10-15

## 目标

任务结果与普通 AI 回复共用消息布局，移除回复里的任务配置和结果引用功能；保留固定会话、累计历史、后台同步和真实终态。任务列表按用户要求展示名称、模型、执行计划、状态、最近一次运行、下一次运行及原有五个操作。

## 步骤

- [x] 移除任务专属回复组件，统一正文、头像和复制操作，正确呈现后台生成状态。
- [x] 删除显式结果引用的前后端链路、类型、无用入口与专属旧测试。
- [x] 调整列表列名与顺序，将下一次运行独立成列；保留查看会话、运行、编辑、归档、暂停/恢复。
- [x] 验证累计历史追问、权限/重试、后台同步和普通聊天流不受影响。
- [x] 更新文档和 note，运行完整检查、构建并在浏览器验证。

## 决策

任务运行元数据继续用于后台同步和隔离，不显示任务名、触发来源、计划时间或任务操作按钮。任务中心仍可配置和取消，聊天可通过 configure_task 修改。删除显式引用 API/字段，不增加旧协议兼容或清理会话历史；追问始终读取固定来源的累计历史。

用户追加列表需求：执行计划显示频率、每周计划的星期和运行时刻，时间统一北京时间。最近一次运行显示实际开始时间，尚未领取则显示入队时间和排队状态；下一次运行显示独立的时间或无后续计划的原因。五个操作位于最后一列，窄屏横向滚动；避免固定过宽操作列遮挡其他字段。

## 验收

成功报告与普通回复使用相同消息结构，正文保持原样，无配置/引用按钮或任务状态卡；进行中仍更新、失败不假装完成。scripts/check.sh 和前端构建通过；浏览器中检查指定历史报告的实际展示。
