# 短信验证注册留痕

状态：已完成
开始日期：2026-11-26

## 目标

管理员可按账号或业务编号查到自助注册的手机号验证记录。用户、租户、手机号绑定及记录在同一事务中提交。

## 背景

短信注册、密码登录和短信登录已接入。当前工作区已实现记录表、写入和管理员查询，需补齐时间校验、管理页、隔离库验收与文档。[短信注册与登录](../../design-docs/sms-registration-login.md)

- [x] 更新 README、设计、索引和运行记录，运行 `scripts/check.sh`。

## 验收标准

- PNVS 明确返回 `PASS` 后注册，管理员可查到注册与核验时间、方式、尾号及唯一编号。
- 核验失败、超时、过期或数据库写入失败时，无残留账号、租户、手机号绑定或成功记录。
- 同一请求并发提交仅成功一次，两种登录路径均保留首次记录；清理短期请求后仍能查询。
- 普通用户不能读取管理员列表中的记录；内置管理员不显示「手机号已验证」。
