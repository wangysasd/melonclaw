# 工作台界面向 Tushare 浅色表面靠拢

状态：已完成
开始日期：2026-11-25

## 目标

在不改变布局、文案、导航、权限和业务流程的前提下，把登录、聊天、拓展、定时任务、知识库和系统管理统一到同一套浅色表面。定时任务页同屏时，「新建任务」为实蓝白字主按钮，「返回聊天」为白底灰边次按钮，表格「运行」为文字按钮。

## 背景

当前工作台使用浅蓝渐变、玻璃高光和多层阴影。本次以设计稿中的页底 `#F6F8FC`、品牌蓝 `#3461FF`、选中底 `#EAEFFF` 和选中字 `#2550E8` 为准。参考首页为 [Tushare](https://tushare.pro/home/#/)。现行视觉契约见 [前端](../../FRONTEND.md) 与 [视觉一致性](../../design-docs/ui-consistency.md)。

- 模型选择器已选行文字为 `#2550E8`、背景为 `#EAEFFF`。

## 风险与依赖

- 浏览器验收使用已启动的本地 Web（`127.0.0.1:8001`）和现有登录数据。缺少的业务状态用脱敏样例补画面，并在验证记录中标明模拟数据。
- RMS 登录需要单独的 `brand=rms` 前端进程，不能改当前默认品牌进程的环境。
- 真实模型回复、附件解析、外部 MCP 和真实删除不作为本次视觉验收前提。
