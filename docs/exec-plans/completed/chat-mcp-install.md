# 聊天安装个人 MCP

状态：已完成
开始日期：2026-10-01

## 目标
用户粘贴 MCP JSON 后，Agent 可用受控工具准备、审批测试和安装到当前用户，凭据不进入模型与消息历史。

## 步骤
- [x] 消息配置提取、持久草稿与个人安装事务
- [x] Agent 工具、审批及运行时注入
- [x] 前端脱敏展示、安装审批与工具目录
- [x] 测试、文档与 scripts/check.sh

## 验收标准
身份和会话隔离、审批拒绝、防篡改、重复确认、JSON 凭据隔离测试通过；scripts/check.sh 通过。

## 决策日志
个人 HTTP/SSE；不支持代其他用户安装、stdio、自动覆盖。连接测试单独审批，安装下一轮生效。草稿存数据库，服务重启后仍可恢复审批。

## 风险与依赖
真实探测依赖远端 MCP；开发模拟身份与宿主网络不构成生产隔离，需要部署方网络出口限制。

## 验证结果

2026-10-01：`scripts/check.sh` 全部通过（后端编译/pytest/ruff/锁文件，前端 eslint/tsc/vitest，文档链接与 diff 空白检查）。真实 PostgreSQL 随机隔离 schema 测试通过，覆盖同一草稿并发确认、不同清单同名冲突回滚、个人偏好、凭据 payload 清理。真实 Agent 图覆盖准备默认参数与测试/安装 approve/reject。前端 Hook 验证原文只进请求，乐观历史、侧栏与失败回填不包含凭据。

本地 `uv run melonclaw-db-init` 成功创建新增草稿表，未清空应用数据。未执行真实外部 MCP 或付费模型端到端联调；连接请求需用户批准，网络出口仍沿用部署边界。
