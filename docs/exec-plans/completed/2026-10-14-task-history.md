# 任务连续执行与会话历史

状态：已完成
开始日期：2026-10-14

## 目标

同一任务持续读取固定会话中的历史、成功进度和用户补充；每次运行只追加一条助手消息。追问和后台执行共用历史投影，模型请求合并相邻同角色文本，数据库保留原消息。

## 步骤

- [x] 实现任务创建摘要、单条助手交付，以及按消息来源固定历史快照。
- [x] 实现共享历史组装、长度预算与摘要、受控原文读取；接入后台和聊天请求副本。
- [x] 验证连续三次创作、追问旧内容、重试稳定、权限、并发和工具消息协议。
- [x] 同步设计、运行说明和本地数据，执行完整检查。

## 决策与边界

三张任务表不变，不增加旧格式兼容。历史快照和摘要使用现有 JSON 元数据；模型凭据仍从数据库解析。后台与聊天共享业务历史，执行状态、工具权限和 Checkpoint 保持独立。只有完整成功的后台结果计入已完成次数，失败或取消不推进。累计历史需要超出窗口时进行有界摘要，原文仍保留并通过只读工具按范围获取。

新增读取工具仅允许当前身份和固定任务会话的本轮历史范围，不读取任意会话、文件或外部服务；不进入 HITL/PTC，不扩大无人值守写权限。历史内容不能作为修改调度或权限的授权；2026-10-15 的[对话配置设计](../../design-docs/task-center.md#对话配置)进一步开放普通聊天主 Agent 在当前用户明确要求时保存本会话任务，后台限制保持。

## 验收

真实离线 Agent 验证第三次生成读取前两次结果；追问可读取早期报告。数据库验证消息不重复、序号不冲突、历史来源在重试期间稳定且租户变化失效。完整 scripts/check.sh 含隔离 PostgreSQL 通过；本地数据只删除旧自动用户触发消息并补创建摘要，保留报告、真实问答及其他业务记录。

有限目标完成通过 complete_task 设置本轮内存标志；仅最终正文成功提交且任务版本未改变时在同一事务暂停未来计划。子 Agent 无此能力，失败/取消不推进，普通循环任务不能因单轮完成而停止。
