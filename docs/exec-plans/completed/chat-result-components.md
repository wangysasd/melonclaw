# 聊天结果组件

状态：已完成
开始日期：2026-10-02

## 目标
在现有聊天里提供可查看、可下载的图片、文件、差异、表格、Mermaid、引用和基础数据图表，使用固定组件与明确的结果协议。

## 背景
Markdown 图片目前是文字占位；已有表格与 Mermaid 缺少结果操作。复用现有工作区、附件归属校验和消息持久化，不引入 A2UI。

## 步骤
- [x] 定义结果块、提示词规则与受控成果文件读取。
- [x] 实现固定组件、Markdown 操作与审批差异复用。
- [x] 验证权限、解析失败、下载与实际组件表现。
- [x] 更新文档、记录验证并执行 scripts/check.sh。

## 验收标准
- 结果块解析失败保留源码；不执行 HTML、脚本或模型提供的任意图表配置。
- 图片与文件请求重新校验会话、用户、项目；路径穿越和符号链接拒绝。
- 折线／柱状图和表格使用同一数据，表格默认折叠，可下载 CSV。
- 组件交互与权限测试、scripts/check.sh、前端构建通过。

## 决策日志
| 日期 | 决策 | 原因 |
|---|---|---|
| 2026-10-02 | melon-result JSON 围栏作为显式结果协议，随消息原文保存 | 避免猜测自然语言类型，也无需另开持久化或 SSE 通道 |
| 2026-10-02 | 成果读取限制在 /outputs/，附件使用 attachment_id | 只公开明确交付目录，避免把工作区内部文件直接开放下载 |

## 风险与依赖
模型可能不遵守协议，需源码回退；来源是回答提供的信息，不声称独立核验。LocalShellBackend 仍只适合本机开发，HTTP 校验不是 Shell 沙箱。成果指向当前文件，不是不可变版本。


## 验证结果

scripts/check.sh 和前端构建通过。真实组件与本地成果读取 HTTP 夹具验证了桌面／390px 窄屏、CSV 数值／单位、Mermaid SVG 导出及文本文件预览。未连接真实数据库／模型／外部 MCP 做端到端验证；来源事实和模型格式遵从性仍由真实使用观察。详细记录见 [设计说明](../../design-docs/chat-result-components.md)。
