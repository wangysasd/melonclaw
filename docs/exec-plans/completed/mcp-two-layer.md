## 工程决定

- 凭据存储决策于 2026-10-01 修订：字面凭据明文存入数据库，管理 API 不回传凭据值。数据库读取权限及备份需按凭据数据保护；当前设计见 [MCP 两层设计](../../design-docs/mcp-two-layer.md)。
- 导入仅前端解析，最大 64 KiB、嵌套 16 层；未知字段和重复键拒绝，不记录输入原文。
- 测试连接超时 15 秒，单进程最多 4 个进行中的测试，取消关闭连接；不调用业务工具。
- 不新增包，不改变架构依赖方向；MCP 管理从既有大文件拆出同包职责模块。
- 不自动清空用户数据库。新结构在隔离测试库验证；实际开发库需要重建时明确报告。

## 风险与依赖

真实服务测试依赖用户配置的 MCP 地址及凭据。开发模拟身份和 LocalShellBackend 的限制保持不变；本任务不实施沙箱。
