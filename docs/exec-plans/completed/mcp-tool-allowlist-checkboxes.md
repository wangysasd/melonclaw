# MCP 工具白名单复选框

状态：已完成
开始日期：2026-10-01

## 目标

在 MCP 编辑器中根据连接测试发现的工具名提供多选白名单，切换到指定工具模式时默认全选。

## 背景

当前白名单要求用户手工输入工具名，容易拼错。MCP 测试连接已负责安全地发现工具，但 API 只返回数量。

## 步骤

- [x] 连接测试安全返回发现的工具名称。
- [x] 前端展示复选框、全选/清空操作，并保持现有 SQL NULL/空列表语义。
- [x] 更新 README、MCP 设计文档和本地 note。
- [x] 检查前端静态校验与相关代码路径。

## 验收标准

- 测试成功后返回工具名称；失败结果不返回名称。
- 选择“仅允许指定工具”后，发现的工具默认全部勾选，可逐项调整。
- 保存时勾选项作为 MCP 原始工具名；全部工具模式保存为 NULL，零选项保存为空列表。

## 决策日志

| 日期 | 决策 | 原因 |
|---|---|---|
| 2026-10-01 | 复用现有“测试连接”作为工具发现入口 | 不自动启动 stdio 程序；发现过程保持显式操作，不新增接口 |

## 风险与依赖

工具名称来自 MCP 服务端；只在有管理权限的测试响应中提供，并作为文本安全渲染。连接测试仍只发现工具，不调用业务工具。

- 通过：前端 TypeScript 类型检查、MCP 编辑器及审批组件 ESLint、MCP 服务 Ruff、`git diff --check`。
- 未运行测试套件或浏览器验证；连接测试与复选框状态按现有类型、服务和组件路径静态检查。
