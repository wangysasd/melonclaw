# 回复流畅性与推理展示

状态：已完成
完成日期：2026-10-03
开始日期：2026-10-03

## 目标

减少重复工具选择，及时展示并行工具结果，保留模型正文与推理的顺序和协议回传，明确等待阶段与耗时。

## 背景

现有标准正文链路已通过离线 HTTP SSE 验证，但选择器每次模型请求重复调用，工具结果逐个消费，第三方推理字段被统一适配器忽略。设计复核记录在本地 note/note.md；长期边界见 [完整消息流](../../design-docs/assistant-message-stream.md)。

## 步骤

- [x] 准备与模型/选择阶段计时、工具生命周期与并发结果投影。
- [x] 会话 Checkpoint 内按用户轮次缓存工具选择，受控目录扩展、选择超时降级。
- [x] 显式推理协议配置、双向模型适配及有序内容块保存与前端展示。
- [x] 行动说明、回归验证、文档与运行验证。

## 验收标准

- 快工具完成时，结果在同批慢工具完成前到达；调用生成与实际执行分开计时。
- 普通工具循环每用户轮次初选一次，恢复复用；不同会话、用户轮次和目录版本隔离；遗漏工具可通过目录检索激活。
- 选择超时和无效结果有界降级，主动取消正常传播；权限、HITL 与 PTC 不扩大。
- 思考与正文交错显示；完成、刷新、取消后保存一致；供应商所需推理字段在后续请求中完整回传。
- 准备、模型首次正文/推理、选择与工具耗时分别可观察；阶段提示和心跳不计作首字。
- scripts/check.sh 全量通过。真实外部模型性能只报告实际运行的样本，不用离线探针宣称节省时间。

## 风险与依赖

推理协议必须显式配置且覆盖工具回传。工具检索只使用当前允许目录，不调用外部服务或调整权限。保持准备阶段真实 HTTP 错误、会话锁、审批恢复和取消语义。保留用户已有未提交改动；不更新 melonclaw-tutorial Skill。


## 验证与交付记录

- `scripts/check.sh` 最终全量通过：后端编译、pytest（含架构/文档链接）、ruff、锁文件，前端 lint、类型检查与 vitest。
- 离线 HTTP SSE 与真实框架链路验证工具调用中的文本即时可见，初选调用顺序从 selector → answer → selector → answer 变为 selector → answer → answer；不推断真实供应商节省秒数。
- 三种非标准思考协议覆盖增量、完整消息、有序块、Checkpoint 和工具结果后的完整回传；签名和加密字段不进入展示。另验证每个标签分片边界、未闭合思考、跨片凭据（含引号、空格、Bearer 与超长 Token）。
- 会话轮次复用、目录扩展、并发隔离、暂停恢复、目录失效与超时降级通过；共享发现预算有界。快工具结果在同批慢工具释放之前可见，queued 不制造开始时间。
- 恢复计时排除等待用户时间，保留之前的子 Agent 轨迹与请求记录；失败只有思考时不复用旧轮次答复。
- 开发服务使用已有 `scripts/restart.sh` 启动。在当前工具环境通过独立进程会话保留服务，避免命令会话结束时清理后台子进程；退出后再次确认后端 HTTP 200 / ready、前端 HTTP 200。
- 页面点击验证未完成：应用浏览器 RPC 初始化遇到运行环境的可信代码路径校验错误；未绕过该校验。前端展示与配置行为由组件/流式归约测试验证。
- 本次未调用真实供应商，未记录外部模型延迟或任务成功率；未修改依赖、数据库表或教程 Skill。使用思考展示前需在供应商编辑页选择实际返回格式。
