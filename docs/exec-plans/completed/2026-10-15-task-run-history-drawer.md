# 定时任务运行记录抽屉

状态：已完成
开始日期：2026-10-15

## 目标

取消独立任务详情页。任务名称直接打开固定会话，点击最近一次运行打开运行记录抽屉；保留列表、五个操作、历史选择、配置快照、失败诊断和取消当次运行。

## 方案与边界

沿用现有 Drawer、Table、Descriptions 与业务 API。TaskCenter 只负责列表、编辑和抽屉入口，TaskRunsDrawer 展示运行历史与选定记录，状态/时间格式拆到 presentation.tsx 共用。删除 TaskDetail 和旧详情布局，不保留兼容入口。抽屉关闭后保留列表筛选/页码；切换任务重新选择历史，单次结果必须匹配当前任务。保存只刷新列表，保存并运行/运行打开会话，不再进入详情。

不改数据库 schema、后端 API、调度、历史结果、模型权限或聊天上下文。取消继续复用确认、幂等键及后台确认终态的规则；测试只用离线替身，不触发真实运行。
