# 任务默认执行模型

状态：已完成
开始日期：2026-10-15
完成日期：2026-10-15

## 目标

新建任务未指定执行模型时使用管理员设置的全局默认模型；已有任务未修改模型则保留原配置。

## 步骤

- [x] 统一系统默认模型的数据库解析，对话保存复用事务连接，无可用全局默认时明确提示。
- [x] 同步工具说明、提示词与表单默认选择，禁止退回聊天模型、个人默认或任意模型。
- [x] 验证默认与显式选择、编辑保留、默认切换后的幂等重放、默认缺失/不可用以及单连接解析。
- [x] 更新说明与开发记录，完成完整检查。

## 决策

系统默认仅指 model_configs 中 scope=global 且 is_default=true 的模型；全局模型仍遵守现有当前用户凭据解析。新建时解析并保存明确 model_id，不改变普通聊天的个人默认模型规则，不自动改写既有任务。

## 验收

隔离 PostgreSQL 与前端回归覆盖系统默认、聊天选择及个人默认不同时的行为；scripts/check.sh 通过。无新增表、升级步骤或历史兼容分支。

## 验证结果

新增 4 项 PostgreSQL 回归，覆盖系统/个人/聊天模型差异、默认切换后的幂等回放、编辑保留及默认缺失/停用/无凭据；配置与普通聊天模型共 30 项测试通过。任务编辑器 4 项回归与完整 scripts/check.sh（含隔离 PostgreSQL）通过，前端生产构建通过。README、设计、架构、前端、AGENTS 和 note 已同步；无需数据库升级或历史清理。
