# MCP 卡片工具详情弹窗

状态：已完成
开始日期：2026-10-01

## 目标

点击 MCP 卡片内容后打开详情弹窗，展示发现到的工具名胶囊及白名单启用数量。

## 背景

当前列表接口只返回 MCP 配置摘要，不包括远端工具目录；编辑器的连接测试只允许配置管理者使用。卡片详情需按当前用户权限安全发现工具名称，并避免在打开卡片时意外启动 stdio 程序。

## 步骤

- [x] 增加受归属、可见性和版本校验保护的工具发现服务/API，结果脱敏并返回启用状态。
- [x] MCP 卡片内容可键盘访问；点击后以弹窗显示状态、启用数量和工具胶囊。
- [x] HTTP/SSE 打开时发现工具；stdio 在弹窗内由用户明确启动发现。
- [x] 同步 MCP 设计文档、README 和本地 note。
- [x] 运行前端类型检查、相关 ESLint、后端 Ruff 与补丁格式检查。

## 验收标准

- 可见且属于当前用户的 MCP 服务只返回工具名称，不回显连接配置、凭据或第三方原始错误。
- 工具数量等于返回的工具项数；白名单内工具显示启用状态，空白名单为零启用。
- 点击菜单、启停按钮不触发详情；点击卡片内容打开详情弹窗。
- 点击 stdio 卡片不会自动启动程序，需用户在弹窗确认发现。

## 风险与依赖

HTTP/SSE 详情发现会连接远端 MCP 并受 15 秒超时和进程并发限流保护。MCP 工具名来自服务端，仅按普通文本渲染。
