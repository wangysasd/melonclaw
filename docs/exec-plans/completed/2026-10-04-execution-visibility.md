# 思考过程与工具调用可见性修复

状态：已完成
开始日期：2026-10-04

## 目标与背景

用户反馈思考过程为空、位置在完成状态之前，不需要「查看耗时」，完成后无法直接看到工具调用。当前前端为所有完成回复渲染空思考栏，并默认收起全部执行步骤。数据库中所选回复没有保存可读推理；当前供应商显式思考格式为标准 OpenAI。

## 步骤

- [x] 阅读当前消息归约、执行组件、推理协议及数据库中的非敏感配置和步骤信息。
- [x] 仅展示实际思考内容，将其置于执行摘要下方；移除耗时明细入口，保留摘要耗时。
- [x] 有工具调用或子 Agent 事件时完成后默认展示时间线，工具详情仍按需展开。
- [x] 验证实际供应商思考字段，核对当前配置与响应协议。
- [x] 补回归验证，同步 README、前端约定与设计文档，运行完整检查和页面验证。

## 验收标准

- 没有 reasoning 内容时页面不生成空思考栏；有内容时位于执行摘要之后。
- 完成及刷新后工具名称和状态默认可见，参数、结果可展开；同名调用分别保留。
- 页面没有「查看耗时」入口，运行状态和总耗时仍可见。
- `scripts/check.sh` 通过；本地浏览器验证完成回复及历史回放。

## 关键取舍与边界

只调整前端展示和必要的现有供应商配置，不新增事件或表结构，不从普通正文合成思考，不回填不存在的历史推理。计时事件继续用于真实阶段和诊断。现有脱敏、权限、审批和工作区边界不变。
