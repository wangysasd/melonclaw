# MCP 卡片健康状态胶囊

状态：已完成
开始日期：2026-10-01

## 目标

在 MCP 卡片上显示连接发现状态；正常时显示工具数量，异常时使用红色标识。

## 背景

卡片目前只显示配置和启用状态，用户无法判断已启用的服务是否能连接。已有受权限和版本保护的工具发现接口，可用于检查连接。

## 步骤

- [x] 已启用 HTTP/SSE 服务加载后检查工具发现状态；stdio 不自动启动。
- [x] 卡片增加正常、异常、检测中、未启用和待检测状态胶囊。
- [x] 与详情弹窗的工具发现共享状态，发现成功显示工具数量。
- [x] 同步 README、MCP 设计文档与本地 note。
- [x] 运行定向 ESLint、TypeScript 类型检查与补丁格式检查。

## 验收标准

- MCP 工具发现成功时，卡片显示绿色正常状态和支持工具数。
- MCP 工具发现返回失败时，卡片显示红色异常状态。
- 未启用服务不发起探测；stdio 不因加载列表而启动，只在用户显式发现后更新。
- 超时或管理 API 不可用时不误报 MCP 异常，显示未知/待检测状态。
