# JWT 与 Anthropic 审查修复

状态：已完成  
开始日期：2026-11-23

## 目标

修复工作区审查确认的七个问题，保留现有 JWT 生命周期、凭据优先级与资源版本发布。

## 步骤与验收

- [x] 共用业务身份入口拒绝已停用租户，同一 JWT 的会话查询仍返回 200。迟到的 401 仅影响发送该请求的令牌。
- [x] Anthropic 连接测试和远端列表发送正确的路径及认证头，且禁止自定义头覆盖解析出的 Key。供应商写入与文档解析模型创建在同一目录锁下校验。
- [x] 部署启动前验证 JWT 配置，附件预览测试使用受控 Blob 请求并通过全量检查。

## 依赖

供应商 HTTP 请求用本地模拟传输验证。真实 PostgreSQL 并发用例使用隔离测试库。

## 验证记录

- 2026-11-23，默认配置下后端、前端及空白检查通过。依赖真实数据库和外部服务的用例按各自前置条件跳过。
- 隔离 PostgreSQL 与 pgvector 上，认证、语音、模型管理、并发配置与账户生命周期定向检查 241 项通过。调整环境变量路由对 403 的旧断言后，环境 API、账户、供应商并发和发版检查合计 23 项通过。前端定向 60 项通过，原有 3 项 Composer 测试恢复通过。
- 发版用例使用替身命令验证停服顺序。缺失、过短的 JWT 密钥或非法有效期均在调用 sudo 和 systemctl 前退出。
- 启用 PostgreSQL 的全量对比中，当前 HEAD 已失败的 63 项仍失败，另有一个停用租户的环境 API 用例使用了旧的 401 断言。该用例已改为会话查询返回 200、环境写入返回 403，并通过上述定向重跑。迁移问题见 [D17](../tech-debt-tracker.md#待处理)。
- 供应商请求使用模拟 HTTP 验证。真实 Anthropic 和生产部署未运行。
