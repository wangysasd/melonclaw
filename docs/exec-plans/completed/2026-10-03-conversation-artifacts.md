# 对话产物抽屉与 HTML 预览

状态：已完成
开始日期：2026-10-03

## 目标

正文成果链接和回复末尾文件卡片打开同一右侧抽屉；抽屉汇总完整会话的文件交付，支持隔离的自包含 HTML 预览，始终读取当前文件。

## 背景

现有 [聊天结果组件](../../design-docs/chat-result-components.md) 已提供 /outputs/ 受控读取和文件结果块，但 HTML 仅下载、文件预览使用 Modal。用户明确不要交付快照。

## 步骤

- [x] 草稿设计写入 note/note.md；新增统一的消息成果引用提取、完整会话产物查询和 HTML 预览边界。
- [x] 接入终态与历史消息，实现文件卡片、链接、产物抽屉与刷新行为。
- [x] 增加权限、提取、HTML 响应与交互回归测试，并检查桌面及窄屏布局。
- [x] 同步 README、架构、前端和设计文档；运行 scripts/check.sh 与前端构建。

## 验收标准

- Markdown 成果链接和 melon-result 文件引用按路径去重；代码块、来源引用和过程消息不进入交付列表。
- 未加载的历史消息仍能出现在会话产物列表；同路径保留最近交付来源。
- HTML 下载保持 attachment，预览响应具有 sandbox/CSP/无缓存及权限核验；拒绝超限与非 UTF-8 预览。
- 卡片与链接统一打开抽屉；会话切换清空；再次交付不重载已打开的 iframe；刷新读取当前文件。
- scripts/check.sh 和 npm --prefix frontend run build 通过。
