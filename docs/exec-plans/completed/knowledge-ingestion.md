# 知识库文档导入与固定 OCR

状态：已完成（2026-11-07修复后复验）
开始日期：2026-11-06

## 目标

实现 PDF、PNG/JPEG、TXT/Markdown 上传→逐页解析→分块→固定嵌入→原子发布的真实闭环，不接入检索或聊天。

## 设计

OCR 固定 DeepSeek-OCR，URL/模型/Key/超时/token 上限从根 .env 经 config 读取，无用户入口、模型切换或凭据回退。PDF 文本层按页提取，不足页渲染图片 OCR；grounding 原始输出与页码保留，索引正文去除标记，字符 offset 对应最终全文。空页、截断或失败不发布残缺版本。固定八表、run_token、本地执行实际退出后释放槽，原子发布正文/chunk/有效指针/job/事件；替换失败旧版继续可用。
