# Skill 管理一致性与生命周期

状态：已完成
开始日期：2026-09-29

## 目标

完成身份与有效状态统一、个人/全员操作分离、保留身份的更新、可恢复安装删除、内容预览及诊断。

## 步骤

- [x] 统一范围身份和有效状态，Picker、管理页、Agent 挂载共用结果。
- [x] 增加内容摘要、来源、版本、更新预览与并发检查。
- [x] 将草稿持久化，增加文件操作日志与恢复入口。
- [x] 完成前端操作、正文/文件差异/依赖预览。
- [x] 补充回归测试、文档，运行 scripts/check.sh。

## 验收标准

同名不串内容；停用/损坏不进入 Agent 目录；更新保留 ID 和偏好；失败/中断可恢复；跨进程草稿可确认；删除不会被重建复活；预览不执行代码；完整检查通过。

## 决策日志

| 日期 | 决策 | 原因 |
|---|---|---|
| 2026-09-29 | 保留 global/user 和显式范围管理 API；选择器使用带范围的标识，数据库 UUID 保留资源身份 | 不增加新的共享层级，消除重名歧义 |
| 2026-09-29 | 同一数据根使用文件锁和持久操作日志；更新需校验预览时的版本及内容 | 覆盖多进程竞争与进程中断，不引入分布式队列 |
| 2026-09-29 | Agent 挂载有效目录的只读派生快照，每轮刷新摘要 | 原先挂载整个根目录，且上游只在首轮加载摘要，会绕过个人启停效果 |

## 风险与依赖

数据库结构直接重建，不写迁移。文件锁要求同机或支持 POSIX 锁的共享文件系统。开发模拟身份与 LocalShellBackend 边界保持不变。真实模型、外部 MCP 不属于离线检查。
