# 对话配置任务

状态：已完成
开始日期：2026-10-15
完成日期：2026-10-15

## 目标

用户可以在普通会话通过对话创建任务，在任务固定会话追加对话修改当前任务；表单与聊天共用配置保存、权限、版本和幂等边界。

## 背景

任务已有固定会话、累计历史和 Web 内置调度，但配置入口仅限表单。用户明确要求将配置能力开放为聊天工具，保持三张任务表和一个任务一个会话。相关设计见 [任务中心](../../design-docs/task-center.md)。

## 步骤

- [x] 扩展保存用例，支持绑定当前普通会话、部分配置更新和消息绑定校验。
- [x] 增加任务配置工具，接入普通聊天主 Agent，读取当前配置与可用模型，明确创建/修改意图及时间规则。
- [x] 验证创建、修改、启停、并发版本、幂等重放、权限、执行快照和实际 Agent 工具调用。
- [x] 同步设计、使用说明和开发记录，完成完整检查并归档计划。

## 验收标准

- 聊天创建后 tasks.conversation_id 等于当前普通会话，不额外创建会话，不插入模拟用户消息。
- 修改只改变提供的字段；版本冲突不覆盖；同一工具调用重放不重复写入。
- 跨用户、失效租户、项目会话、后台和子 Agent 无配置权限。
- 已开始的运行快照保持，后续运行读取新配置；结果继续追加原会话。
- 实际离线 Agent 工具调用、PostgreSQL 专项测试及 scripts/check.sh 通过。

## 风险与依赖

配置意图和文本要求提取依赖模型判断；服务端负责结构、归属、版本和幂等校验。时间固定北京时间，仅支持现有四类计划。验证使用隔离 PostgreSQL 与离线模型，不调用付费外部模型。

## 验证结果

新增 9 项对话配置专项通过，背景受限工具新增 configure_task 拒绝用例。实际 Deep Agents 离线工具调用、数据库事务、单连接解析、当前会话绑定/历史保留、部分编辑、启停和并发版本均通过。完整 scripts/check.sh（含真实 PostgreSQL 隔离测试）及前端生产构建通过，前端 349 项回归通过。首轮完整检查在并行构建时有一个账户表单测试超时；该用例单独重跑及随后完整检查通过，无需改动账户代码或延长超时。

未改数据库 schema、依赖或运行入口，无需升级/清库。本地服务已重启，原有两条任务、两份报告和固定会话可读，执行器就绪。实现位置与长期边界已同步 [任务中心](../../design-docs/task-center.md#对话配置)、README、架构、前端和开发约定。
