## 目标

文件面板直接展示登记附件和 outputs 第一层内容，以来源胶囊替代两个入口目录，并保留其他工作区文件和真实目录结构。

## 验收标准

- 默认列表没有「上传附件」和 outputs 包装目录，两个来源直接子项可见。
- 同名项按实际引用分别保留，输出子目录按需展开，其他根目录文件仍可访问。
- 附件和输出行显示来源；本对话产物筛选继续使用交付索引。
- 来源分页、选中项定位、预览返回、隐藏取消和部分失败有回归覆盖。
- scripts/check.sh 与 npm --prefix frontend run build 通过。

## 风险与依赖

各来源分页独立，列表只对已加载项排序；加载更多可能插入前面的名称。目录变化不保证快照一致性。浏览器验证依赖现有本地开发服务。
