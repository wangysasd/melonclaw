# 按模型配置上下文窗口

状态：已完成
开始日期：2026-10-04

## 目标
数据库 model_configs 明确保存每个模型的 context_window，默认 1,000,000 tokens；压缩按 .env 的默认 80% 比例触发。

## 步骤
- [x] schema、创建/编辑 API、仓储与模型解析贯通。
- [x] 模型管理界面支持填写与修改窗口，Agent 按所选模型计算阈值。
- [x] 测试默认值、参数校验、切换模型与配置版本失效；同步文档并全量检查。

## 验收标准
默认窗口 1,000,000 对应 800,000 token 阈值；配置小窗口时独立计算；移除全局窗口环境变量；scripts/check.sh 通过。

## 决策与边界
1M 定义为十进制 1,000,000。触发比例乘完整窗口，输出预留另行校验安全余量；摘要近期保留预算保持既有配置。开发期仅改 schema，不写旧数据库兼容或迁移，已有数据库需要清空重建；不自动删除用户当前数据库。
