# 统一意见反馈入口

状态：已完成
开始日期：2026-11-28

## 目标

访客从登录页、登录用户从头像菜单打开「意见反馈」。反馈、投诉和举报使用通用表单，内容旁移除独立举报按钮。管理员在既有「投诉举报」中处理。

## 步骤

- [x] 复用通用工单表单，将违法有害内容等已有原因开放给通用反馈。
- [x] 移除助手回复、知识库文档行和原文抽屉的入口，保留阅读与查询流程。
- [x] 同步用户说明并验证提交、查询以及原文打开。

## 验收标准

- 访客可以提交投诉举报并凭编号与查询码查询。登录用户可以在「意见反馈」提交并查询自己的工单。
- 回复、文档行和原文抽屉不展示单独举报入口。引用原文照常打开。
- 管理员仍可处理既有工单，通用工单只保存用户主动填写的说明和联系方式。
