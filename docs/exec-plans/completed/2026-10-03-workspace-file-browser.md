## 目标

右侧抽屉默认浏览当前对话实际工作区的目录与文件，保留本对话产物筛选、消息卡片直达预览和当前文件语义，不创建快照。

## 验收标准

- 普通对话读取独享目录，项目对话读取项目工作区；仅展开导航项目不改变当前对话的文件范围。
- 默认全部文件可查看非 outputs 文件；系统隐藏目录与符号链接不可枚举或读取；上传附件只通过登记信息与既有 API 展示。
- 目录按需读取、单目录有界与分页，支持搜索／排序、返回目录与当前文件选中。
- 本对话产物仍来自完成回复；未交付文件无伪造交付来源。
- 文件列表刷新不重载已打开 HTML；旧卡片打开当前文件，删除／重命名后保留错误入口。
- 没有文件写入 API、Agent 工具、数据库表或快照；全部检查、构建通过。

沿用现有开发模拟身份与 LocalShellBackend 限制；新接口逐次校验用户、会话和项目，并通过目录 fd 与 NOFOLLOW 读取。HTML 继续使用当前自包含 sandbox/CSP 预览，不扩展外部资源或多文件站点。文件系统变化不是交付事件，不推断某个文件由哪条回复创建。
