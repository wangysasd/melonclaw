本目录只保留当前实现的设计与验证边界。模块存在不代表所有页面已挂载；未验证的外部服务、数据库和生产行为必须明确标注。历史方案被替代后，将仍有效的约束合并到现行设计，再删除旧方案，避免靠末尾追加「覆盖前文」维持互相冲突的说明。

执行步骤与有日期的验收记录放在 exec-plans；未解决的实现缺口放在技术债清单。note 只保留当前实现的补充笔记，不作为事实来源。上游框架行为应注明核实版本，升级时复核。
