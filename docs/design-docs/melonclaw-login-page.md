# MelonClaw 浅蓝登录页

状态：已实现

## 背景与目标

用户选择第二套浅蓝玻璃 AI 概念图，统一登录页与应用现有蓝色体系。

## 方案与关键选择

桌面左侧约 44% 显示原字标、「开启智能协作」标题和开放式表单，标题下不再显示辅助文案；品牌蓝圆形光晕局部位于登录表单后方，外侧保持白色留白。延续 RMS 登录页的品牌蓝与 10% / 6% / 2% 强度层级，并把外围渐变提前淡至透明，避免出现矩形边界。登录按钮居中显示，宽度为表单的 50%。右侧显示本地浅蓝玻璃轨道环与 AI 核心 WebP。正文与标签 14px，控件 44px；900px 以下隐藏配图并居中表单，短屏自然滚动。保留字标原红绿色，主要动作使用共享品牌蓝。图片失败不会阻挡登录。

## 数据流与安全边界

复用 Vite 的 `brand?.trim().toLowerCase() === "rms"` 构建常量，只有 RMS 使用原 RMS 分支；空值及其他值使用本页。认证仍走 getAuthConfig、login、passwordlessLogin；免密入口只由后端配置开放，错误原位显示并保留输入。无工具、权限、数据库或模型解析变化，无第三方素材请求。

## 运行与预期结果

修改 dev 的 `.env` 或 prod 的 `.env.prod` 中 brand 后重启前端或重新构建。`brand=rms`（含大小写混合）展示 RMS；空值及其他值展示本页。不需要 db-init 或 db-update。

## 验证记录

`scripts/check.sh` 全部通过。真实浏览器验证 1440×1024 桌面与390×844窄屏布局、44px控件、14px标签、无横向溢出及必填提示；控制台无错误。品牌判断复用现有归一化开关；RMS布局和认证分支沿用原实现。视觉对照与修订记录见根目录 `design-qa.md`。
