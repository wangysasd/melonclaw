# MelonClaw 浅蓝登录页

状态：已实现（2026-11-27 重构）

## 背景与目标

统一登录页与清透冰蓝磨砂工作台的视觉体系，解决叠加短信登录、自助注册、隐私说明、意见反馈入口及 ICP 备案页脚后的层级混乱与底部遮挡问题。

## 方案与关键选择

- **居中一体化双栏舞台**：外底沿用工作台 `--workspace-canvas`（`#e8eff7`）浅冰蓝柔光画布，居中呈现 `16px` 圆角一体化双栏容器（`.login-stage`，最大宽度 `1120px`），与登录后的 `.home-workspace` 保持一致的空间语言。
- **左侧品牌视觉区**：展示重新生成的无文字 3D 清透磨砂蓝/淡青/薄荷绿玻璃雕塑本地 WebP（`frontend/public/assets/brand/melonclaw-login-glass.webp`），与工作台玻璃图标及清透表面材质同源，无多余营销标语或第三方素材请求；图片加载失败不阻挡登录。
- **右侧认证表单区**：背景复用 `--chat-surface` 顶部淡冰蓝柔光，顶部左对齐展示透明底字标（`melonclaw-word-transparent.webp`）与 `24px / 32px / 600` 标题「开启智能协作」。
- **清晰的操作层级与模式切换**：
  - 后端开启 `sms_login` 时，登录态顶部提供线形页签切换，以浅色底部分隔线和蓝色下划线标记当前方式（「账号密码登录」/「短信验证码登录」），并在表单底部提供「忘记密码」入口；同时开启 `registration` 时，底部左右分别展示「忘记密码」与「注册账号」。注册态展示「创建新账号」，找回密码态展示「找回密码」（通过手机号验证码设置新密码后返回密码登录并预填用户 ID），两者底部均提供返回登录入口。
  - 主提交按钮（「登录」/「注册并登录」）居中，使用浅蓝渐变，最大宽度为 240px。「获取验证码」使用白底次操作按钮（`action-secondary`）。dev「免密登录」使用密码登录按钮下方的灰色文字入口。
  - 「隐私说明」与「意见反馈」统一收纳在底部正常文档流辅助区（低干扰文字按钮/链接），下方承接 `FilingFooter`，彻底消除固定定位遮挡；点击底部或短信说明中的「隐私说明」均先保存草稿且不发码。
- **响应式与无障碍**：正文与标签 `14px`，桌面控件 `40px`、平板与手机（`900px` 以下）保持 `44px` 触控高度；`900px` 以下隐藏左侧配图并以居中圆角卡展示，`520px` 以下铺满移动端白底表面，零横向溢出并尊重 `prefers-reduced-motion`。

## 数据流与安全边界

复用 Vite 的 `brand?.trim().toLowerCase() === "rms"` 构建常量，只有 RMS 使用 RMS 品牌素材与标题分支；空值及其他值使用本页。两种品牌共用 `LoginPage` 双栏舞台与 `AuthPanel`：默认账号密码登录，短信登录、自助注册和免密入口均由 `GET /api/auth/config` 返回的布尔开关控制。错误原位显示并保留输入，密码不裁剪，关闭浏览器自动填充。底部「意见反馈」可未登录打开 `ReportPortal`，见[投诉举报与反馈](reports.md)。无第三方素材请求。

## 运行与预期结果

修改 dev 的 `.env` 或 prod 的 `.env.prod` 中 `brand` 后重启前端或重新构建。`brand=rms`（含大小写混合）展示 RMS；空值及其他值展示本页。不需要 `db-init` 或 `db-update`。
