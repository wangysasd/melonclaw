# 侧栏项目与会话管理

状态：已实现。

## 背景与目标

项目和对话此前只能创建、打开，不能在侧栏整理。现在每行在悬停、键盘聚焦时显示“…”操作入口；触屏设备始终显示入口。菜单提供置顶/取消置顶、重命名和红色删除项。

## 方案与数据流

项目展开后在本行下展示该项目会话，并将左侧文件夹换成展开图标；再次点击收起。项目行右侧“…”后提供新建会话图标，随时可在该项目下创建；仅项目内没有会话时，展开区额外显示「在此项目中新建对话」。项目会话保持首次 10 条和独立分页，普通会话仍在“最近会话”中。服务端持久化 `is_pinned`，项目与会话各自按置顶、更新时间、ID 排序；会话游标包含置顶状态，翻页不会重复或跳过普通项。

前端调用项目/会话的 `PATCH` 更新名称或置顶状态、`DELETE` 删除。服务层先按当前模拟用户和租户运行上下文校验归属，仓储再按 `user_id` 限定写入。删除时将状态标记为 `deleted`，列表和历史读取都排除已删除项目及其会话；已删除项目中的会话不能继续访问。重命名限制项目 120 字、会话 200 字。删除进行中的会话会返回冲突。

输入框上方的灰色项目栏只复用现有 `session.projectId`，无需新增后端状态。选择菜单可搜索项目、调用现有新建项目弹窗，或退出项目。侧栏切换和输入框选择器通过同一全局状态联动；选中当前项目不会调用可切换关闭的 `openProject`，避免误关闭。

普通会话行的“…”菜单在删除项下方增加「移动到项目」级联项。子菜单先显示「新建项目」，再显示
当前用户的已有项目；项目内会话不展示移动项。选择已有项目后直接调用专用移动 API；选择新建
项目则复用新建项目弹窗，创建成功后将原普通会话移入该项目。移动成功后刷新最近会话和项目
列表；若移动的是当前打开的会话，切换为项目会话上下文并重新加载历史和附件作用域。

## 取舍、失败与安全边界

开发期保留被删除资源的数据库记录和工作区文件，以免删除请求同时破坏消息、附件、Checkpoint 等跨系统状态；界面删除表示资源不可再访问，不等于物理清理。侧栏确认弹窗会提示项目下的会话也将从列表移除。无真实生产身份认证，仍沿用开发模拟用户边界。置顶、重命名失败时列表保持原样并显示服务端错误。
会话移动期间禁用重复点击，服务端重新验证用户与项目归属；运行中、等待交互、存在暂存附件或
目标文件同名时会返回明确错误，源会话保持原位。新建项目成功但后续移动失败时，新项目仍保留，
可从普通会话菜单重新选择它。

## 运行与验证

数据库字段只由 `database/schema.py` 声明；已有开发数据库须清空后执行 `uv run melonclaw-db-init` 重建。运行后从侧栏展开项目、悬停行并操作菜单，可观察置顶排序、名称更新、删除后列表与历史不可访问。验证包括前端菜单/文件夹状态测试、类型检查、lint、后端 schema 测试以及 `scripts/check.sh`。
