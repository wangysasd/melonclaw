# 前端视觉一致性

状态：已实现（2026-10-18 精修）

## 背景与目标

原有 CSS 使用 14px 业务文字，但 Ant Design 默认 16px；控件、卡片、浮层的圆角和间距各自维护。保留中性灰、系统蓝、品牌图形以及既有导航，通过共享基础参数消除视觉漂移。不调整业务逻辑、接口、权限或路由，不增加依赖。

## 方案与关键选择

`frontend/src/theme/tokens.ts` 是基础参数的唯一来源。`antd.ts` 将数值参数映射到 ConfigProvider 与 XProvider；App 输出同源 CSS 变量，业务 CSS 消费既有语义变量。CSS 不再另行维护根 Token。

| 语义 | 规范 |
|---|---|
| 正文 | 14px，22px 行高，400 |
| 次级 / Caption | 13px / 12px |
| 工作台顶栏标题 | 16px / 32px，600 |
| 欢迎页主标题 | 24px / 32px，600 |
| 卡片 / Section 标题 | 16px / 24px，600 |
| 大 Section | 18px / 26px |
| 按钮、单行输入、选择器 | 默认 32px，小型 28px，大型 40px；圆角 6px |
| 卡片 | 圆角 8px，padding 16px，gap 16px，无默认阴影 |
| Modal / Drawer | 标题与正文 20px 24px，底部 16px 24px；Modal 圆角 12px |
| 页面左右留白 | 桌面 24px，768px 及以下 16px |
| 图标 | 默认 16px，强调 18px，导航 18–20px，辅助 12–14px |
| 字重 | 400 / 500 / 600 |
| 间距 | 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40px；按钮图文间距 6px |

资源页面共用标题、工具栏、Section 标题、卡片网格和空状态。网格按实际可用宽度排列，最小列宽 280px。技能与连接器采用分区底栏：标题完整换行，更多菜单位于右上角；内容区 16px 留白，白色底栏通过细分隔线划开，内边距 12px 16px。技能来源/版本胶囊与 32px 主操作在同一底栏垂直居中。描述最多两行，完整内容由可键盘打开的详情入口访问，异常说明不截断。MCP 主体保留协议、配置范围及有意义的用途描述；空描述不增加占位，精确的“聊天安装”说明移至底栏右侧，原始字段和搜索仍完整保留。MCP 底栏左侧显示真实使用/不可用原因，不能解读成实时连接健康。供应商精简卡保留紧凑形态与正式 Logo。搜索靠左，操作靠右；窄屏自然换行。环境变量沿用 Tab 容器留白，不再二次内缩。

拓展、定时任务、系统管理及既有品牌占位页必须复用 `WorkspaceHeader`，不在页面 CSS 内单独定义顶栏标题。统一为 49px 高（32px 控件 + 上下 8px + 底边框 1px）、16px / 600 标题、32px 行高，窄屏也不放大。标题与图标在左；拓展与定时任务顶栏右侧统一为“返回聊天”，安装、新增等业务操作放在正文工具栏右侧。定时任务工具栏左侧为搜索、状态筛选，右侧为“新建任务”和刷新图标按钮，窄屏自然换行并保持右对齐。页面左右留白为桌面 24px、窄屏 16px。定时任务正文不显示顶部说明文字；列表与管理表格由顶栏下的内容区域独立滚动。任务表格填满父容器，宽表格只在自身区域横向滚动；表头与单元格间距来自 Ant Design 主题，操作按钮 32px。状态使用统一语义颜色并保留文字，时间使用等宽数字。运行记录抽屉用中性标题区与分隔线组织历史、快照、错误和操作，关闭不改变列表筛选与分页。

普通卡片只用轻边框；侧栏保留原有轻磨砂，聊天顶栏与输入区采用实色表面。登录页保留两套品牌插图及字标，表单背景去除额外渐变。消息无入场位移；尊重 reduced-motion，组件状态切换不引入阅读位移。

普通按钮、表单与弹层优先使用 Ant Design component token / semantic styles。原生按钮补统一 focus-visible；保留 Sender 自身输入区聚焦语义。hover 通过颜色表达，不移动普通按钮。危险操作继续沿用原有 danger 与确认流程。

## 数据与事件流

仅增加主题参数到组件与 CSS 的单向映射。账号与环境变量弹窗保留 Ant Design 关闭生命周期，以恢复触发按钮焦点；内容仍在关闭后销毁。资源卡片 DOM 顺序为详情内容、右上菜单、底栏主操作，独立入口保留各自键盘语义。长技能标签在输入区保留单行省略，完整名称可通过提示与无障碍名称访问，观察标签宽度调整首行缩进，避免窄屏与文字重叠。用户身份、列表请求、流式事件、模型选择、审批和安装事件链路不变。不存在额外接口或数据库写入。

## 边界

- 聊天外层阅读宽度仍为 800px，扣除头像与间距后，过程、正文、表格和代码共用可用宽度，不另设 680px 上限。输入区共用 800px 上限与页面边距。长文与代码保留阅读行高；Markdown 标题保留相对层级，段落与列表间距 12px，引用间距 16px。输入区聚焦仍保持中性边框，无新增蓝色光晕。
- “回到最新消息”按用户选择保留原有胶囊外观：最小高度 36px，内边距 6px 12px，圆角 999px；仅此按钮例外。
- 状态点、用户头像、滚动条保持圆形；消息气泡保留方向；触屏审批与结果操作保留 44px 点击区域。
- 品牌 Logo、供应商 Logo 与稳定首字母配色保留，不将品牌色误当作状态色。
- MCP 工具详情继续使用固定头尾与滚动正文；没有改变打开详情可能触发发现的行为。
- 项目当前没有独立智能体管理或独立设置路由；不为这次视觉优化新建页面。
- 数据图表、Mermaid 和真实模型回复内容不改；不会为视觉检查调用模型、安装技能或连接外部 MCP。

## 运行与验证

沿用 `cd frontend && npm run dev`；无需初始化数据库。执行 `scripts/check.sh` 和前端生产构建。
