# 前端视觉一致性

状态：已实现（2026-10-02）

## 背景与目标

原有 CSS 使用 14px 业务文字，但 Ant Design 默认 16px；控件、卡片、浮层的圆角和间距各自维护。保留中性灰、系统蓝、品牌图形以及既有导航，通过共享基础参数消除视觉漂移。不调整业务逻辑、接口、权限或路由，不增加依赖。

## 方案与关键选择

`frontend/src/theme/tokens.ts` 是基础参数的唯一来源。`antd.ts` 将数值参数映射到 ConfigProvider 与 XProvider；App 输出同源 CSS 变量，业务 CSS 消费既有语义变量。CSS 不再另行维护根 Token。

| 语义 | 规范 |
|---|---|
| 正文 | 14px，22px 行高，400 |
| 次级 / Caption | 13px / 12px |
| 页面标题 | 24px / 32px，600 |
| 卡片 / Section 标题 | 16px / 24px，600 |
| 大 Section | 18px / 26px |
| 按钮、单行输入、选择器 | 默认 32px，小型 28px，大型 40px；圆角 6px |
| 卡片 | 圆角 8px，padding 16px，gap 16px，无默认阴影 |
| Modal / Drawer | 标题与正文 20px 24px，底部 16px 24px；Modal 圆角 12px |
| 页面左右留白 | 桌面 24px，768px 及以下 16px |
| 图标 | 默认 16px，强调 18px，导航 18–20px，辅助 12–14px |
| 字重 | 400 / 500 / 600 |
| 间距 | 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40px；按钮图文间距 6px |

资源页面共用标题、工具栏、Section 标题、卡片网格和空状态。网格按实际可用宽度排列，最小列宽 280px；单卡不会撑满所有空列。卡片顶部为操作预留空间，长标题不与操作重叠。供应商精简卡保留紧凑形态。

普通按钮、表单与弹层优先使用 Ant Design component token / semantic styles。原生按钮补统一 focus-visible；保留 Sender 自身输入区聚焦语义。hover 通过颜色表达，不移动普通按钮。危险操作继续沿用原有 danger 与确认流程。

## 数据与事件流

仅增加主题参数到组件与 CSS 的单向映射。用户身份、列表请求、流式事件、模型选择、审批和安装事件链路不变。不存在额外接口或数据库写入。

## 边界

- 聊天阅读宽度仍为 800px，长文与代码保留阅读行高；Markdown 标题保留相对层级。
- “回到最新消息”按用户选择保留原有胶囊外观：最小高度 36px，内边距 6px 12px，圆角 999px；仅此按钮例外。
- 状态点、用户头像、滚动条保持圆形；消息气泡保留方向；触屏审批与结果操作保留 44px 点击区域。
- 品牌 Logo、供应商 Logo 与稳定首字母配色保留，不将品牌色误当作状态色。
- MCP 工具详情继续使用固定头尾与滚动正文；没有改变打开详情可能触发发现的行为。
- 项目当前没有独立智能体管理或独立设置路由；不为这次视觉优化新建页面。
- 数据图表、Mermaid 和真实模型回复内容不改；不会为视觉检查调用模型、安装技能或连接外部 MCP。

## 运行与验证

沿用 `cd frontend && npm run dev`；无需初始化数据库。执行 `scripts/check.sh` 和前端生产构建。

浏览器使用现有本地后端数据，检查聊天欢迎页、技能、连接器、模型、项目弹窗、系统状态和连接器编辑。1440、1280、1024、768 四档资源页面无文档水平溢出；可见工具栏按钮均为 32px，未捕获页面 JavaScript 异常。检查弹窗 12px 圆角、键盘焦点与窄屏换行。动态生成中的聊天内容和真实外部服务不在本次浏览器验证范围，行为回归由既有测试覆盖。
