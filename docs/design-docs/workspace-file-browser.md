# 会话／项目文件浏览器

状态：已实现
日期：2026-10-04

## 背景与目标

产物索引回答「这段对话交付过哪些文件」，文件浏览器回答「当前工作区里有哪些文件」。项目中的其他会话、用户上传和工具生成的文件可能已经存在，却没有出现在当前对话的最终回复中。右侧抽屉扩展为实际工作区文件浏览器，同时保留原来的交付入口与来源。

用户明确不需要快照。文件直接读取当前工作区，不保存版本、副本或新的数据库记录；历史卡片也是当前文件的入口。

## 方案与关键选择

- 顶部入口为「文件」，默认「全部文件」。普通会话读取独享持久目录，项目会话读取共享项目目录。范围由服务端核验当前会话的归属，侧栏项目展开状态不参与判断。
- 「本对话产物」继续使用完成回复派生的完整会话索引，不用目录变化推测交付事件。浏览普通文件时仅在匹配本对话索引后提供「定位到回复」。项目文件可来自其他会话，但不伪造当前对话的来源。
- 一次枚举一个目录，目录优先，支持名称搜索、名称／最近修改排序及分页。每页最多 200 项，单目录最多扫描 5,000 项；超限提示拆分子目录。目录不递归扫描，不监听整个文件树，不建立文件索引表。
- 默认根视图直接合并登记附件、outputs 第一层内容和其他工作区根项，不显示「上传附件」／outputs 包装目录。附件按原始文件名展示并复用既有附件元信息／内容 API，输出项继续使用实际路径；行尾「上传／输出」胶囊仅说明来源区域。同名文件和目录按真实引用分别保留，不拼接内容。内部 `.attachments` 及其他隐藏路径仍不可直接枚举或读取。
- 各来源独立分页，已加载项统一按文件夹优先、名称排序；加载更多可能插入名称较早的项，不承诺尚未读取项的全局顺序。来源加载失败时保留成功来源和已加载页，错误单独重试。
- 首版只读：浏览、预览、源码和下载。没有上传、编辑、重命名或删除操作。
- 成果引用协议仍只接受 `/outputs/` 和真实附件 ID。浏览器单独使用 `workspace_path` 打开其他普通文件，不将更宽的路径权限加入模型成果 JSON。

## 交互与数据流

点击「文件」→ 现有接口校验有效用户／会话／项目 → 并行读取工作区根目录和登记附件 → 确认根目录中的 outputs 后读取其第一层 → 合并到统一根列表。真实目录继续行内逐级展开；只读取可见的来源和按需展开的子目录，不递归扫描整个工作区。根目录分页较多时，通过加载更多发现 outputs；若选中的文件位于 outputs，则按需翻根目录页直到发现来源，再定位输出页或祖先子目录。附件同样按真实 ID 定位后续页。工具栏保持刷新和右侧范围 segments，不增加搜索框或排序菜单。

点击正文链接／末尾卡片／产物筛选项 → 同一预览组件 → 当前文件内容。消息入口首次打开时按需定位所在目录和页；从列表打开则保留分页与滚动位置。消息中的产物卡片显示文件名、类型和大小，不显示内部路径；文件浏览器的预览工具栏仍显示当前路径。文件与当前文件标签平级切换，附件沿用登记列表。删除或重命名后保留卡片的不可访问错误，不指向另一个文件。

统一根列表可见且各来源都未翻页时，每 5 秒重新读取各来源首屏；新增 outputs 可由根目录下一次轮询发现。完成回复触发列表更新；任一根来源翻页后停止首屏轮询，使用明确刷新以免丢失已加载页。真实子目录只在展开时按需读取，明确刷新才重读已加载子目录。预览打开时隐藏并保留目录列表，隐藏时停止轮询、中止在途请求；重新显示恢复已加载页，列表请求不重载预览。HTML 在预览／源码切换和后续交付时保持同一 iframe；只有明确刷新才重读内容。关闭、导航和身份切换中止旧请求并忽略迟到响应。

桌面沿用可调宽度的右侧面板；1100px 以下覆盖聊天区，设置 dialog／inert 并提供关闭与焦点循环。可见按钮和范围 segments 参与焦点管理，正文以 14px 为主，窄屏主要操作至少 44px。

## 实现与 API

- `storage/workspace_files.py`：虚拟路径验证、逐层目录 fd、NOFOLLOW、普通文件读取、有界目录枚举。
- `services/results.py`：沿用 ConversationService 和 ChatRuntime 解析实际工作区，调用存储与仓储接口。
- `repository/attachments.py`：按用户和实际归属筛选登记附件，排除删除／过期项，名称搜索按字面值匹配。
- `api/routes/files.py`：`GET /api/conversations/{id}/files?path=/&q=&sort=name&offset=0&limit=200`，返回 path、scope、items、total、next_offset；sort 可为 name 或 modified。
- 同前缀 `/attachments` 返回原始文件名及分页登记信息；`/metadata`、`/content`、`/html-preview` 接收工作区虚拟 path。内容响应复用成果下载和 HTML 预览策略。
- `WorkspaceFileBrowser` 管理真实目录树、来源胶囊和定位；`hooks/useWorkspaceFileListing` 组织统一根视图的独立来源请求、分页、错误重试、轮询与保留；`lib/workspaceFileListing` 映射来源并按实际引用去重和排序；`ArtifactWorkspace` 管理筛选、选择、预览与交付来源；`lib/workspaceFiles.ts` 区分浏览引用和成果引用。

## 失败与安全边界

每次请求重新校验有效用户、会话和项目。目录必须位于当前实际工作区；拒绝相对路径、空路径段、点开头的文件／目录、跳转、控制字符和反斜杠。目录与文件逐层打开 fd，不跟随符号链接，只接收目录或普通文件；读取继续使用已打开的描述符，避免路径替换后读到另一个目标。错误通过统一 API 映射脱敏，不输出宿主机绝对路径。

目录条目可能在枚举后被修改或删除，预览时再次校验。分页期间目录变化可能改变排序或条目位置；客户端按路径／附件 ID 去重，明确刷新重新从首屏读取。对一个正在原地写入的普通文件，当前读取可能遇到写入中的内容；不提供版本一致性或历史恢复。

所有新增接口只读，没有新增 Agent 工具、PTC 能力或审批清单项；原有文件生成与写入仍走受控工具边界。开发模拟 user_id 和 LocalShellBackend 不构成生产认证或安全沙箱。

HTML 沿用自包含 UTF-8、2,000,000 字节上限、可信 meta／HTTP CSP 和无同源权限 sandbox；不开放 CDN、相对多文件站点、主应用 API 或外部资源。浏览器限制不替代共享部署的身份与执行隔离，完整限制见 [HTML 产物设计](conversation-artifacts.md)。

## 简化后的面板结构

第一行固定「文件」与单个当前文件标签，关闭文件回到列表。文件列表工具栏左侧仅提供刷新，右侧用单选 segments 切换全部文件／本对话产物；目录默认按名称排序，不提供搜索框和排序菜单，上传附件和 outputs 第一层内容直接展示，行尾用来源胶囊说明区域；真实文件夹点击后行内展开子项。预览工具栏提供路径、下载与更多菜单；下载文字为 13px，HTML／Markdown 使用单选 segments 切换预览和源码。元信息与定位回复收进更多菜单。常规内容区不叠加卡片标题或元信息条；文件列表单行、14px、浅灰选中。放大且视口超过 1100px 时可以展开辅助目录导航，普通抽屉不额外分栏。

关闭面板保留浏览选择与列表状态，但释放预览 Blob 和请求；重新打开读取当前文件。切换会话/用户清理全部面板状态。没有数据库、依赖、接口或 Agent 工具变化，仍是只读浏览。

新增回归覆盖搜索/滚动保持、列表与预览切换时 iframe 保留、关闭后恢复、隐藏目录停止轮询与分页保持。
