# 安全自评与监管协查

适用于 MelonClaw 正式部署。运营方填写实际负责人和证据位置，完成演练后再据实填报。注册核验、日志留存与协查是三项独立证据。

## 责任与值守

| 职责 | 运营方登记 |
|---|---|
| 安全管理负责人及联系方式 | ［姓名、内部电话或邮箱］ |
| 投诉值守与备岗 | ［姓名、备岗、检查频次］ |
| 协查经办与复核 | ［人员或岗位、内部联络方式］ |
| 对外反馈 | 登录页「意见反馈」及已公开、实际值守的邮箱 |

站内工单由值守人员打开「系统管理 → 投诉举报」检查。受理后核查事实，记录采取的措施，向投诉人反馈并办结。发现共享资料有继续扩散风险时，可按[知识库处置流程](knowledge-base.md#管理员停用恢复与删除)先暂停相关知识库，再核查。公开响应时限由运营方按实际值守安排核定。

## 账号名称和昵称的举报处置

1. 通过统一「意见反馈」受理账号名称或昵称举报。访客从登录页进入，登录用户从头像菜单进入。可选「其他」，涉及骚扰或滥用时可选相应类别。可在说明中提供相关账号 ID 或显示名称、出现位置和时间；无需提供密码、验证码或完整手机号。
2. 值守人员在「系统管理 → 投诉举报」受理并登记线索，在「用户管理」用用户 ID 或名称核对账号。名称可能重名，确认对象后再处置。举报情况与当前显示不一致时，记录核查依据与结论。
3. 核实为违规显示名称时，管理员可在「用户管理」编辑用户名称。若涉及不可编辑的用户 ID，或问题需要进一步限制账号使用，由安全管理负责人按用户协议评估现有账号管理措施。记录实际执行的措施、时间和经办人，向投诉人反馈并办结。

正式演练可用测试账号和无害的临时昵称，经意见反馈受理后在用户管理更正昵称，再办结并查询结果。证据使用脱敏记录。

## 正式环境取证

开始前记录域名、版本、时间和经办人，核对正式环境已关闭开发免密及身份切换。证据使用受控目录，填报附件取脱敏副本。手机号、验证码、口令、令牌、匿名查询码和无关业务正文不得纳入证据。

| 项目 | 操作 | 合格证据 |
|---|---|---|
| 网络与操作日志 | 使用组织控制的测试账号，从外网经过正式站点登录并发送一条无真实业务数据的测试消息。在运维端核对两条审计记录和入口连接信息。若存在 CDN 或负载均衡，核对源地址和端口来自哪一跳。 | 展示同一测试账号的操作、时间、结果、源地址及端口、目标地址及端口的脱敏样例。来源不是本机反代回环地址。核对运行版本至少保留 184 天，归档轮转不提前清除；上线不足 184 天时记录实际启用日期。 |
| 自助注册核验 | 使用运营方控制的测试手机号，在正式站点经真实短信自助注册。管理员在「系统管理 → 用户管理」按测试账号或验证编号核对记录。 | 用户 ID、注册时间、核验成功时间、方式、手机号后四位及验证编号。使用测试账号并遮盖不必要的字段。操作完成后按现行账号管理流程决定是否停用或软删除测试账号。 |
| 其他账号核对 | 确认正式环境是否存在后台创建或历史遗留的普通账号。如无此类账号，记录「无」；如存在，抽查开设方式和实际核验资料。单独核对内置管理员。 | 按实际账号类别登记。内置管理员按管理账号说明；后台创建或历史账号仅在实际存在时单列。首次绑号记录证明绑号时的短信校验。 |
| 投诉办结 | 登录页提交一份明确标有「演练」的匿名测试投诉。管理员受理，可结合上节演练更正测试账号的昵称，填写实际措施及公开反馈并办结。回到登录页用编号和查询码查结果。 | 受理时间、实际措施、已办结状态和对用户可见的反馈。查询码只供演练操作使用。 |
| 模拟协查 | 用模拟文书给出一个测试账号、一个时间范围和所需字段，按下节流程取证与复核。 | 脱敏台账、材料清单和内部模拟交付记录。没有真实案件时，统一标记「演练」，交付只在内部进行。 |

生产演练结果单独登记，记录日期、版本、经办人、操作结果、证据位置和未覆盖项。本地模拟、公开配置探测、正式环境联调分别标注。

## 监管协查步骤

1. **受理与核验。** 由安全管理负责人通过已知官方渠道核验来函机关、经办人员、法律文书、请求权限、数据范围及反馈时限。有疑问时通过官方渠道回拨确认，核验完成后再调取。
2. **登记与授权。** 在受控台账登记文书、时间窗口、对象、字段、经办人和复核人。按核验结果授权相关人员读取；需要保全且数据可能到期时，按请求范围及时留存受控副本。
3. **最小范围提取。** 管理员按账号或验证编号查注册核验记录，按工单编号查处置历史。授权运维人员按账号和时间查独立审计文件。涉及对话内容时先核验文书范围和数据是否仍存在，由授权人员按限定会话和时间窗口提取。关联对象或字段查不到时，在台账明确记录。用记录标识及材料清单注明来源和生成时间。
4. **复核与交付。** 复核人员比对文书范围、筛选条件、交付材料及接收方。通过机关确认的安全渠道交付，登记交付时间、回执编号及材料清单，真实数据仅按依法确认的范围提供。
5. **归档。** 台账和凭证保存于限制访问的运营存储，按适用期限及保全要求维护。结束后按约定处置临时工作副本。

## 协查台账模板

台账保存在有访问控制的运营存储。下表只提供空白字段，材料正文、账号秘密和查询码另按授权处理。

| 事项编号及类型 | 发文机关及文书编号 | 受理时间及核验方式 | 账号／对象及时间段 | 授权调取范围 | 经办及复核 | 材料清单／缺失说明 | 交付渠道、时间和回执 | 状态 |
|---|---|---|---|---|---|---|---|---|
| ［正式／演练］ | ［填入］ | ［填入］ | ［按需最小化登记］ | ［填入］ | ［填入］ | ［填入］ | ［填入］ | ［待核验／处理中／已结项］ |

模拟文书可使用 `DRILL-001`，范围只包括一个测试账号指定时段内的注册核验编号、登录结果以及单个测试工单的办结结果。复核时尝试加入一个无关账号，确认该账号的记录被排除。验证后的材料留在内部，台账交付渠道填写「内部模拟」。
