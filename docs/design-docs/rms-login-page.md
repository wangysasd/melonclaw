# RMS 登录页

状态：已实现

## 背景与目标

以第二幅概念图的浅蓝品牌分栏风格改善登录页；右侧使用第一幅图的精简表单，并按用户要求移除欢迎语和产品描述。仅在 RMS 品牌下生效。

## 方案与取舍

左侧占约 56%，以浅蓝玻璃环为背景，仅显示「让研究更进一步」，不放置左上角字标；标题采用系统字体、常规字重和柔和深蓝灰。右侧采用第一幅概念图的居中品牌构图，Logo 与表单背后使用品牌蓝径向渐变光晕（半径随右侧区域尺寸变化：横向85%、纵向68%；中心 10% 不透明度，向外自然淡出）：表单上方展示 160px RMS 字标，留出 48px 间距后显示用户 ID、密码、宽度为表单 50% 的居中登录按钮与按配置开放的免密文字按钮，不显示「欢迎回来」「欢迎使用 RMS 投研助手」和「RMS · 投研助手」。不保留此前建筑配图、图注及页脚。

装饰图为随前端发布的本地 WebP，避免第三方图片请求和完整页面截图造成的不可交互 UI。正文沿用 14px，控件沿用触控高度和圆角 Token。900px 以下隐藏配图和品牌主标题，保留右侧居中 Logo 与表单；短屏允许自然滚动。非 RMS 品牌使用[MelonClaw 浅蓝登录页](melonclaw-login-page.md)。

## 数据流与安全边界

Vite 读取现有 `brand` 开关，去空格并忽略大小写后注入品牌布尔常量。`getAuthConfig` 决定免密入口；用户 ID 和密码仍由原登录接口处理，免密仍由原免密接口处理。品牌不改变身份权限或认证规则。错误原位显示，保留表单输入；装饰图片使用空 alt，失败不阻止登录。无数据库、运行入口或工具变化。

## 运行与验证

配置 `brand=rms`，重启前端或重新构建，未登录时打开页面：预期桌面显示左右布局，窄屏显示单列表单。其他品牌显示 MelonClaw 浅蓝登录页。验证包括 `scripts/check.sh`、真实浏览器截图、响应式布局和原登录交互测试；本次最终记录见根目录 `design-qa.md`。无需数据库初始化或升级。
