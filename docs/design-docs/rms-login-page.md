# RMS 登录页

状态：已实现（2026-11-27 布局统一）

## 背景与目标

保留 RMS 品牌的浅蓝玻璃环视觉与精简品牌文案，同时与 MelonClaw 共用重构后的一体化双栏舞台、线形页签登录方式切换和正常文档流合规底栏，消除短信/注册/投诉入口叠加后的布局混乱与底栏遮挡。仅在 RMS 品牌下生效。

## 方案与取舍

- 与 MelonClaw 共用居中 `16px` 圆角双栏容器（`.login-stage`）及 `--workspace-canvas` 浅冰蓝外底，右侧采用 `--chat-surface` 柔和顶光。
- 左侧保留既有本地浅蓝玻璃环 WebP（`rms-login-glass.webp`）与左上角柔和深蓝灰「让研究更进一步」主标题，不放置左上角字标。
- 右侧顶部居中展示 `melonclaw-word-rms.png` 字标，不显示「开启智能协作」「欢迎回来」「欢迎使用 RMS 投研助手」或「RMS · 投研助手」文案；认证表单、线形页签切换（短信登录启用时）、居中主操作提交按钮（最大宽度为 240px）、白底次操作「获取验证码」、密码登录按钮下方的 dev「免密登录」文字入口以及底部正常流「隐私说明 · 意见反馈」与 `FilingFooter` 均与默认品牌保持一致。
- `900px` 以下隐藏左侧配图与标题，居中展示表单卡片；`520px` 以下切换为全宽移动端布局，保持 `14px` 正文与 `44px` 触控控件高度。非 RMS 品牌使用[MelonClaw 浅蓝登录页](melonclaw-login-page.md)。

## 数据流与安全边界

Vite 读取现有 `brand` 开关，去空格并忽略大小写后注入品牌布尔常量。右侧表单与 MelonClaw 共用 `AuthPanel`。`getAuthConfig` 决定免密、短信登录和注册入口；品牌不改变身份权限或认证规则。底部「意见反馈」打开共享投诉页，见[投诉举报与反馈](reports.md)。错误原位显示，保留表单输入；装饰图片使用空 `alt`，失败不阻止登录。

## 运行与验证

配置 `brand=rms`，重启前端或重新构建，未登录时打开页面：桌面展示一体化双栏登录页，窄屏展示单列表单。其他品牌展示 MelonClaw 浅蓝登录页。2026-11-27 已在 Chromium 下核验 `1440×900`（密码/短信/注册/投诉）与 `375×812` 布局无横向溢出、底栏无遮挡，并随全量前端单测与 `scripts/check.sh` 校验通过。无需数据库初始化或升级。
