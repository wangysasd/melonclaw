# 常驻全局导航

状态：已实现（2026-10-05）。

## 背景与目标

把页面导航与聊天项目、会话导航分开。常驻图标栏参考 Codex 的窄栏布局，保留现有拓展功能及后端契约。

## 方案与关键选择

- `GlobalNav` 提供 Home、拓展、系统状态、模拟用户菜单，宽 48px，支持选中态、悬停和键盘提示。
- `Sidebar` 只管理项目与会话。Home 不改折叠偏好；收起按钮保持原位，展开入口位于聊天顶栏。窄屏继续使用抽屉。
- `Workspace` 切换页面时隐藏 Home 容器而不卸载聊天，保留流连接、Composer 草稿及附件状态。切用户以用户 ID 重建聊天和侧栏，避免旧用户状态残留。
- 拓展 TAB 使用 `melonclaw.resource_tab.v1` 保存技能、连接器或模型的选择。存储失败不妨碍导航；无效值回到技能。模型选择器入口显式跳模型 TAB。
- 拓展内部保留现有管理组件，不做全面改版。

## 数据与事件流

导航点击 → Workspace 改变可见区域 → 保留会话选择与聊天组件。聊天隐藏期间仍接收原 SSE；滚动回调不操作隐藏元素。返回时按原来是否在底部决定跟随最新内容或恢复 scrollTop。翻看历史时复用已有未读消息提示。用户切换继续通过 Session 清理流与上下文。

## 失败与安全边界

不新增 API、表、Agent 工具或权限。不读取凭据；系统状态反映已有服务状态，不代表 MCP 连接探活。模拟用户仍仅用于开发。浏览器刷新不承诺恢复未发送草稿、附件或运行连接，TAB 与桌面折叠偏好可保留。

## 运行与预期结果

按 README 启动前后端，无需重新初始化数据库。收起聊天侧栏后切拓展再返回，侧栏仍收起；点击顶栏展开可找会话。输入草稿、添加附件后切换拓展再返回，输入区保持。生成中切换页面，回复继续；阅读历史时返回不跳底，原本在底部则跟随。用户菜单清楚标记当前用户。
