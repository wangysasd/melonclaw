# 欢迎页研究方向引导

## 背景与目标

七个分类卡与问题卡并列争夺注意力，分类混用对象、来源和工作方式，重复说明挤占首屏。目标是帮助用户快速选一个可编辑问题开始。

## 方案与关键取舍

欢迎页保留个股与公司研究、行业与策略研究、专家观点、研究资料与报告、业绩与市场复盘、债券与信用、宏观/资金/多资产七个分类，采用无说明、无外框的轻量标签，选中时显示浅蓝底；每个标签左侧配 16px 同色线性图标，复用现有 Icon 资源，卡片保持纯文字。保留原引导词卡片的标题、说明、提示词及网格布局，移除卡片装饰图片，每类至少八张，桌面四列、默认展示八张（两行），其余通过“更多问题”展开；窄屏卡片单列。点击仅填入可编辑草稿，不自动发送。顶部保留精简标题与较小 Logo，不重复展示分类标题和操作说明。

按用户反馈保留原七分类和问题库，不合并分类或改写引导词。只简化分类标签及顶部重复说明。

## 数据流与失败、安全边界

方向切换 → 本地筛选并收起展开列表 → 点击问题 → ChatView 草稿 → 用户补充条件并发送。点击不调用模型或工具，不新增权限和持久化数据。外部数据缺失、资源未启用仍由原聊天链路处理，不作能力保证。

## 运行步骤与预期结果

按 README 启动应用，打开空会话；默认选中个股与公司研究并展示八张问题卡片（四列两行）。切换方向、展开和收起不发送请求；点击问题后可编辑再发送。窄屏允许标签换行和内容滚动，不产生横向溢出。无需数据库初始化或升级。
