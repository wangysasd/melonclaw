# 首页权益与固收引导

## 背景与目标

新增 DM MCP 与固收 Skill 后，为空会话补充可编辑的固收研究起点，并让用户快速区分权益和固收。

## 方案与设计选择

首页共 23 个独立提示词，两页各展示 12 张卡片，按「权益 / 固收」两个 TAB 分组，每次只显示一组，默认打开权益；两页首张均为共用的「了解助手能力」。每 8 秒自动交替激活，手动点击或方向键、Home/End 可切换。鼠标悬停、键盘焦点位于引导区或页面隐藏时暂停轮换，离开后重新计时；组件卸载清理定时器。首张「了解助手能力」随当前 TAB 使用同组配色（权益浅蓝、固收浅青绿），背景、边框、图标和悬停样式均保持一致；11 张原有 CICC/HTSC 研究卡归权益，使用浅蓝底；11 张固收研究卡归固收，使用浅青绿底。标题与正文均为 14px，宽屏三行四列、平板两列、窄屏一列。卡片不显示右上角类别标签，按钮支持键盘聚焦。

DM 入口包括债市日报、资金市场、主体信用、机构行为、债券行情、债券发行、国债期货、境外债券、收益率曲线、信用利差和债券到期。前四项对应运行时四个固收 Skill；其他入口对应数据库登记的 DM MCP 领域。宏观与资产入口沿用原有研究分类，不表示宏观分析仅限权益。

## 数据流与边界

静态卡片点击 → ChatView 草稿 → 用户补充条件 → 既有 Composer 发送链路。点击不执行工具、不新增权限，不改变数据库与 Agent 装配。静态入口不代表当前资源已启用；实际可用性受 MCP、Skill、订阅权限及脚本依赖约束。提示要求注明数据时点、来源和缺失项，信用估计与事实区分。
