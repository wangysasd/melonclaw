# 首页权益与固收引导

## 背景与目标

新增 DM MCP 与固收 Skill 后，为空会话补充可编辑的固收研究起点，并让用户快速区分权益和固收。

## 方案与设计选择

首页共 20 张卡片。首张「了解助手能力」保持中性灰白；11 张原有 CICC/HTSC 研究卡归权益，使用浅蓝底；8 张 DM 卡归固收，使用浅青绿底。标题与正文均为 14px，宽屏四列、平板两列、窄屏一列。卡片不显示右上角类别标签，按钮支持键盘聚焦。

DM 入口包括债市日报、资金市场、主体信用、机构行为、债券行情、债券发行、国债期货和境外债券。前四项对应运行时四个固收 Skill；其他入口对应数据库登记的 DM MCP 领域。宏观与资产入口沿用原有研究分类，不表示宏观分析仅限权益。

## 数据流与边界

静态卡片点击 → ChatView 草稿 → 用户补充条件 → 既有 Composer 发送链路。点击不执行工具、不新增权限，不改变数据库与 Agent 装配。静态入口不代表当前资源已启用；实际可用性受 MCP、Skill、订阅权限及脚本依赖约束。提示要求注明数据时点、来源和缺失项，信用估计与事实区分。

## 运行与验证

按 README 启动应用并打开空会话，检查卡片类别与响应布局。点击任意卡片后应仅填入输入框，可编辑后发送。工程验证使用 `scripts/check.sh`；不需要数据库升级或重新初始化。真实 DM 数据和海报生成依赖对应订阅、凭据及渲染环境，本次不调用外部数据接口。

本次验证：`scripts/check.sh` 全部通过（后端编译、pytest、ruff、锁文件，前端 lint、类型检查、vitest，文档链接与空白检查）。未进行浏览器视觉验收或真实 DM 外部调用。
