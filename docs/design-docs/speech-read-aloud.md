# 朗读助手回复

状态：已实现。

## 背景与目标

已结束的助手回复需要能被朗读。交互对齐 [DeepSeek chat-demo](https://github.com/deepseek-ai/chat-demo) 的朗读：同一时间只读一条，空闲、加载、播放三种状态，再点一次停止。合成使用 [DeepSeek 语音合成](https://api-docs.deepseek.com/zh-cn/guides/tts) 的整段接口，返回边合成边传输的 PCM。不使用 WebSocket，也不在模型仍生成时提前开读。

## 方案

助手消息操作区在「复制」后面放「朗读」。点击后浏览器向 `POST /api/speech/synthesize` 提交会话、消息和音色。服务端确认会话属于当前用户，只读取这条助手消息已保存的 `content`，再用 `load_settings().deepseek_api_key` 请求 `https://api.deepseek.com/v1/tools/tts`。上游返回 200 后，页面按 24 kHz、16 bit、单声道 PCM 排队播放。

凭据只有根目录 `.env` 的 `DEEPSEEK_API_KEY`，与语音识别、联网搜索和网页读取相同。Key 为空时返回「语音合成尚未配置。」，聊天和启动不受影响。不读取模型供应商、个人模型或 `model_configs` 的 Key，Key 和上游地址不下发到浏览器。

## 数据流

1. 已结束且有正文的助手回复显示朗读按钮。生成中、待完成、空白、用户消息和乐观消息不显示。
2. 点击时同步创建 24 kHz `AudioContext` 并 `resume`，然后才发起请求。
3. 请求体只有 `conversation_id`、`message_id`、`voice_id`。音色缺省为海星 `stella`，另一项是暗潮 `tide`。
4. 服务端在身份共享锁内校验 Cookie 和会话归属，随后释放锁再调用 DeepSeek。不可见会话保持「会话不存在或不属于当前用户。」消息不存在或不是助手消息时返回「消息不存在。」不支持的音色返回 400。
5. `pending` 返回「回复尚未结束，暂时不能朗读。」空白返回「没有可朗读的文本。」正文原样提交，`format` 为 `pcm`，`filter_markdown` 为 true。
6. 汉字（统一表意文字及其扩展区、兼容汉字）每个计 2，其余每个码位计 1，上限 10000。序列化后的上游 JSON 超过 64 KiB 同样拒绝。超限不截断、不访问网络。
7. 收到上游第一块 PCM 后返回 200。音频字节流的 `Content-Type` 为 `application/octet-stream`，`Cache-Control` 为 `no-store`，并标明 24000 Hz、单声道、16 bit。
8. 第一段可播放数据到达后，按钮从加载变为播放。每段音频在排入前登记结束事件，流关闭且末段播完后回到空闲。

## 设计选择

- 朗读是页面操作，不是 Agent 工具，不进审批或代码解释器，也不写入消息、附件、Checkpoint 或追踪。
- 音色记在浏览器 `melonclaw.tts_voice.<userId>`，非法值回退海星。切换音色不打断当前播放，下一次点击生效。
- 全页同时只有一条。再点当前条、改听另一条、发送、停止生成、切换用户或会话、离开聊天页和卸载都会停止。主动停止不提示错误。
- 上游 401 映射为 503「语音合成鉴权失败。」，避免浏览器把它当成登录过期。400 为「这条回答暂时无法朗读」，429 为请求过多，503 为服务繁忙，504 或超过 31 分钟为超时，其余失败为「朗读失败，请稍后再试。」
- 每个用户同时一个合成，进程内还有全局并发上限。服务端从打开上游连接开始监听浏览器断开。断开、超时和失败都会关闭上游 HTTP 连接并释放名额。音频不落盘。
- 减少动效时，状态竖条使用静止帧。按钮本身不缩放、不位移、不循环闪动。

## 失败与边界

流已经出声后中断，或正常结束但没有采样，页面停止播放并提示「朗读失败，请稍后再试」。其他失败展示服务端固定文案。单个 Web 进程的闸门不能限制其他进程共用同一账户。不调节语速，不支持断点续读，不自动播放，也不提供音频下载。

接口清单、自动化用例和真机验收步骤见[语音测试用例](speech-test-cases.md)。

后端用例使用假的 HTTP 客户端。覆盖文本和音色校验、消息归属，以及身份锁在上游请求前释放。断开测试覆盖等待响应头、等待读流和发送受阻，并检查连接关闭和并发名额释放。

前端用例覆盖音色存储、按钮可见性、PCM 排队和失败收尾，并验证末段已播完、HTTP 流随后才关闭的情况。真实播放取决于浏览器音频权限和有效的 `DEEPSEEK_API_KEY`。
