# 知识库

知识库把资料导入一次，之后在多个会话里检索和引用。它和当前对话的附件、跨会话记忆是分开的。入口在左侧窄栏的「知识库」，不在「拓展」里。页面右上角「返回聊天」会回到原来的会话。

定时任务不读取知识库。用户没有在输入区选中知识库时，不能声称已经查过这些资料，也不能扫描全部私有库。

## 创建与共享

点「创建知识库」，填写名称和描述，选择查看范围后保存。新建默认是「同租户」。描述会帮助聊天判断资料范围，聊天里最多使用前 300 个字符。分块大小默认 800 字，重叠默认 120 字；重叠不能超过分块大小的 20%。之后修改分块设置不会自动重切已发布的文档。

| 查看范围 | 谁可以查看和下载 |
|---|---|
| 所有人 | 所有有效用户 |
| 同租户 | 与所有者当前租户相同的用户。转让后范围跟着新所有者 |
| 指定人 | 所有者、点名成员和系统管理员。创建时最多选择 100 位查看者 |

列表里的「成员」分开管理三件事：

1. 「默认查看范围」选出范围后，点「保存范围」才生效。改成「指定人」需要确认。
2. 「单独授权」可增加查看者或编辑者。撤权只移除这条单独授权；仍在默认范围内的人，以及系统管理员，还可以访问。
3. 所有者可展开「所有权设置」转让。转让后原所有者成为编辑者。

查看者可以检索和下载原件。编辑者还可以上传、替换、删除、重试和取消处理。库设置、共享和删除由所有者或系统管理员操作。

## 导入资料

点知识库名称，或在操作列点「上传」，打开详情里的「文档」。再点「上传文档」选择文件。「支持的格式」按类型列出扩展名。

可导入 PDF、Word（DOC、DOCX）、PowerPoint（PPT、PPTX）、PNG、JPEG、WebP、GIF、BMP、TIFF、TXT 和 Markdown。TXT 与 Markdown 在本地读取。其余类型整份发送到 DeepSeek 文字识别，按成功识别的页计费。知识库不接受 Excel、CSV、JSON 和 ZIP。

默认单文件 50 MiB、PDF 100 页；部署调整后，超出限制的原因显示在状态列。同一库一次处理一份资料，其他库可以同时处理。处理期间已发布的原文仍可检索和下载。文档列表每 5 秒刷新，也可点「刷新文档」。

状态从「排队」到「处理中」，处理中会显示解析、分块、向量化或发布。出现「可检索」后才能用于检索和聊天。失败原因和下一步显示在状态列。PDF 中既无文字也无图片的空白页会导致整份失败，按提示删掉该页后重新上传。

失败或已取消时，编辑者可以选择「重试原文」或「替换」。「重试原文」使用原来的文件和该版本的分块设置。文字识别已经成功、但后面的分块、向量化或发布失败时，重试可能再次计费。单次识别默认最多等待 180 秒；页面超时后，远端仍可能完成并计费，所以失败不会自动重试。修改部署 Key 或识别时限后需要重启服务，再点「重试原文」。

删除文档会立即停止访问并取消处理，已经出现在历史聊天里的内容不会被追回。

Key 未配置时，TXT 和 Markdown 仍可导入；PDF、Office 和图片失败，状态列显示「OCR 配置无效。请联系维护人员修正后重试。」这时联系维护人员，不要改聊天模型。

## 在聊天里检索

输入框左下角加号旁边是「选择知识库」，可搜索并多选，最多 20 个。入口会显示「知识库 · 已选 N」。同一会话里选择会保留，直到改选、清空，或切换会话、项目、用户。每条消息只带上发送或加入队列当时选中的库，不会从更早的历史消息恢复。

本轮选中库的名称和描述会提供给模型。模型按需检索，选了多个库也不保证每个库都会被查询。聊天固定同时使用关键词和向量；向量服务超时或故障时，可能只返回关键词结果，并在工具回执里标明降级。权限或配置错误不会改成另一种检索。

回答旁可以展开「知识库来源」。打开引用时会再次检查权限。资料删除、清理或失去权限后，旧引用不可用，也不会用新版本冒充当时的证据。

## 检索测试

知识库详情的「检索测试」只查本库已发布资料，不生成回答。默认「混合检索」，也可改成「向量检索」或「关键词检索」做对照。可限制最多 20 份文档。页面上的排序值用于比较相关性，不代表答案可信。
