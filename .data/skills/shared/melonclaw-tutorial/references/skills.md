# Skill：安装、启用与使用

Skill 是按任务加载的操作说明和参考文件。它不会自动创建模型、MCP 连接或授予额外工具权限。

## 手工操作

1. 打开侧栏“拓展”，选择“Skills”。
2. 点击“上传 Skill”选择 ZIP，或“远程安装”填写 GitHub 地址。
3. 查看正文、文件清单、依赖提示与安装范围，确认安装。
4. 新安装默认停用。普通用户点击“添加到我的技能”；共享 Skill 需要管理员从菜单选择“全员启用”，个人再按需要选择“添加到我的技能”。
5. 点击“使用”，或在聊天的技能选择器选择该技能；也可以直接描述需求，让 AI 自动发现已启用技能。下一条消息生效。

ZIP 必须在根目录包含 SKILL.md，或只套一层目录；一次安装一个 Skill。SKILL.md 的 frontmatter 要有 name 与 description。macOS 元数据会被忽略。

远程来源支持 owner/repo、GitHub 仓库地址或 tree/分支/子目录链接。纯仓库默认 main；名称含斜杠的分支暂不支持。集合仓库需要具体 Skill 子目录，不默认安装全部。当前不支持私有仓库凭据输入。

## 在聊天中安装

上传 ZIP 附件并发送“帮我安装这个 Skill”，或发送 GitHub 链接并说明安装意图。AI 会准备预览，然后显示一次安装审批。

审批重点：名称、来源、个人或共享范围、是否启用。管理员／owner 安装共享资源；若选择启用，将对全员开放。普通用户安装个人资源，仅自己可用。默认准备安装并启用；想只安装可明确说“先不要启用”。

确认后 AI 返回真实结果。安装并启用后下一条消息可用，不需要新建聊天。拒绝后不执行安装；草稿 15 分钟过期，需要重新准备。聊天工具不负责更新同名现有技能，同名冲突请去管理页的卡片菜单选择“上传更新内容”或“从远程更新内容”。

安装不会执行包内脚本或自动装依赖。commands/MCP/config 的依赖提示只帮助排查，不代表安全审计，也不授予权限。MCP 提示可用仅代表已配置，连接结果仍以工具查询为准。

## 停用、更新和删除

“我不使用”只影响自己；管理员“全员停用”影响所有用户。更新保留资源 ID、启停和个人偏好；确认前会检查版本是否变化。删除会移除资源；内容缺失或异常请查看诊断，管理员可用“恢复与检查”。不要通过聊天 Shell 修改内部目录。

教程本身也是共享 Skill，初始化时默认启用；若被管理员停用或个人选择不使用，按上述入口恢复，不绕过禁用状态。
