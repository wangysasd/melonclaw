# 聊天、项目与排障

## 聊天与项目

选择可用模型，输入需求并发送。普通聊天有独立工作区；项目里的会话共享项目文件，但保留独立聊天记录。普通会话可加入项目；运行中会话、未发送附件或目标文件冲突会阻止移动。项目内会话目前不能再次移动。

## 附件

通过聊天附件入口选择文件，上传完成后发送消息。支持图片、PDF、文本、Office 文档和 ZIP；实际类型、数量和大小以附件弹窗显示为准。文档需要等待解析完成，图片需要支持图片的模型。

ZIP 不作为文档解析，不会自动执行；安装 Skill 时明确说“帮我安装”，AI 使用附件 ID 进入受控导入。仅上传文件不会自动安装。普通聊天附件只能在该聊天使用，项目附件可在所属项目内使用，均限当前用户权限。

## 审批与失败

工具审批出现后检查操作内容，选择允许或拒绝并提交。允许仅对本次操作生效，不是长期授权。不要建议用 Shell 绕过审批。安装草稿过期后重新准备，不能复用旧审批安装新内容。

- ZIP 无效：检查是否损坏、密码保护、危险路径、体积或压缩比超限，以及 SKILL.md 结构。
- GitHub 下载失败：检查是否为公开仓库、分支和目录是否正确；网络失败或限流可稍后重试。
- 安装成功但不可用：检查是否启用、共享是否全员开放、个人是否停用，发下一条消息触发刷新。
- 同名 Skill：管理页更新现有项，不反复上传，不自动覆盖。
- 中断后不知道是否成功：先到“拓展 → Skills”核实。管理员可执行“恢复与检查”。不要声称自动重试一定安全。
- 教程或其他 Skill 不出现：检查共享开关、个人偏好和资源诊断。新部署需要管理员完成数据库初始化和 Skill 索引。

回答排障问题时给一个可验证的下一步，说明预期看到什么；不知道当前配置时明确说需要页面状态，不虚构诊断。
