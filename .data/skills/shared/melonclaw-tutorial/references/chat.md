# 对话、语音、搜索与附件

这些能力都在普通聊天里使用。没有单独的开关页面。部署环境未配置 `DEEPSEEK_API_KEY` 时，语音提示尚未配置，文字识别提示「OCR 配置无效。请联系维护人员修正后重试。」，搜索会说明无法调用；文字聊天不受影响。不要让用户把 Key 发到对话里。

## 对话排队

助手正在回复、等待回答或等待确认时，可以先写下一条消息。输入框为空时，按钮是「停止生成」；写了文字或加了附件后，按钮变为「加入队列」。回车提交当前草稿。

待发送消息贴在输入框上方。拖动左侧把手，或聚焦把手后按上下方向键，可以调整顺序；垃圾桶移除该条。当前这轮正常结束后，按队列顺序逐条发送。每条消息沿用加入队列时的模型、技能、附件和知识库，之后再改选择不影响已经排队的消息。

停止、失败或连接中断后，队列会停住并写明原因。确认上一轮已经结束，再点「核实并发送」或「核实上一轮」。图片文字还没准备好时，点「重新识别并发送」。若提示尚未确认上一轮结束，待发送消息会保留。

录音或转写期间不能发送，也不能加入队列；回复过程中的「停止生成」仍可使用。队列只留在当前打开的页面里。切换到其他会话再回来，尚未发出的消息还在；刷新、关闭页面或切换用户后需要重新输入。多个会话可以同时回复，每个会话有自己的队列。

## 语音输入

麦克风在模型选择器和发送按钮之间，悬停提示「语音输入」。页面需要是 HTTPS 或本机页面，否则按钮不可用，并提示非 HTTPS 页面无法使用语音输入。

1. 点麦克风开始说话，再点一次结束。最长 120 秒，到时自动结束。
2. 识别出的文字插入输入框当前光标处。先修改，再自己发送；空结果不会插入文字。
3. 转写过程中再点一次可取消。

离开聊天页，或切换用户、项目、会话时，正在进行的录音和转写会取消。浏览器拒绝麦克风或没有检测到设备时，按页面提示处理。看到「语音识别尚未配置。」时，由部署人员配置 Key 并重启服务。

## 朗读回复

已经结束、并且有正文的助手回复，在「复制」后面显示「朗读」。正在生成、尚未结束、空白回复和用户消息没有这个按钮。

点「朗读」开始播放，再点「停止朗读」结束。右侧小箭头选择音色：默认「海星（女声）」，另一项是「暗潮（男声）」。换音色不打断正在播放的内容，下一次朗读生效。同一时间只朗读一条。发送消息、停止生成、切换用户或会话、离开聊天页都会停止播放。

看到「语音合成尚未配置。」时，处理方式与语音输入相同。过长的回复会直接拒绝，不会截断后继续读。朗读不会自动开始，也没有语速调节或音频下载。

## 网络搜索与网页读取

直接说明要查公开资料或打开某个网页。普通聊天里，搜索资料和读取网页是常驻能力，不经过 MCP，也不会出现在 `list_mcp_tools` 的结果里。不能因为 MCP 清单为空，就说没有联网搜索。

搜索和读取只面向公开网页。返回内容可能被截断；出现截断标记时，那段文字不是完整原文。定时任务在允许搜索时可以检索公开资料，不能抓取任意网址。Key 未配置或调用失败时，按工具回执说明，不编造搜索结果。

## 聊天附件与文字识别

点输入框左下角加号，选择「图片和文件」；也可以把文件拖进输入区，或粘贴剪贴板图片。弹窗标题是「添加附件」，会显示当前生效的格式、大小、数量和页数。常见默认是单文件 20 MiB、一条消息合计 50 MiB、最多 10 个附件、PDF 500 页，以弹窗为准。

文件传完后，需要识别的条目显示「DeepSeek 识别中…」。点确认后，附件进入输入区；取消会删除这次暂存的文件。解析失败时，附件旁有「重新解析」。失败或超时的附件需要重新解析或移除后才能发送。

| 文件 | 处理方式 |
|---|---|
| PDF、Word、PowerPoint、多页 TIFF | 上传时整份识别文字 |
| 普通图片 | 当前模型支持图片输入时直接给模型看；文本模型识别文字。发送前改成文本模型，会补识别尚未准备好的图片 |
| 动图 WebP、GIF | 使用首帧 |
| TXT、Markdown、CSV、JSON、Excel | 在本地读取，不调用文字识别 |
| ZIP | 不解析成文档。安装 Skill 时明确说「帮我安装」，见 [skills.md](skills.md) |

文字识别使用部署环境的 DeepSeek Key，不使用当前聊天模型的 Key。Key 未配置时，本地可读的文本仍可发送，需要识别的文件会失败并给出原因。普通会话的附件只在该会话使用，项目附件可在所属项目内使用。
