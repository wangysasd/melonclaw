# MCP：配置服务与使用工具

MCP 服务向 AI 提供外部工具；安装 Skill 不会自动建立 MCP 连接。

1. 打开“拓展 → MCP 服务”，点击“新建 MCP 服务”。
2. 填写服务标识和传输方式。普通用户只能创建个人 http/sse 服务，填写服务方提供的地址；不要把文档页地址当成接口地址。
3. 如有鉴权参数，在页面的相应配置字段填写。不要在聊天里提供 Token 或含凭据 URL。
4. 保存并启用，回到聊天发送新消息，让 AI 查询当前 MCP 清单。

管理员可管理共享服务，包括 stdio；普通用户不能使用 stdio 或 ${VAR} 环境变量占位符。没有 MCP 也能正常聊天。具体工具是否被发现、连接是否失败，以 `list_mcp_tools` 返回为准。

排障时先查询清单：未出现的服务检查页面开关和归属；failed 检查地址、网络和鉴权；ready 但工具少检查工具白名单。不要仅凭当前模型只看到少数工具就声称 MCP 没有配置，系统会动态选择工具。

stdio 和外部工具可能有副作用，按应用审批和权限边界处理；LocalShellBackend 不是安全沙箱，共享部署需要可信认证与执行隔离。
