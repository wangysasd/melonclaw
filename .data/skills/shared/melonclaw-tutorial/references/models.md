# 模型：供应商、Key 和默认模型

入口是“拓展 → 模型”，也可从聊天模型选择器底部“添加自定义模型”进入。

## 普通用户

1. 选择已有供应商，填写自己的 API Key。
2. 添加个人模型，模型标识填写供应商实际支持的标识；可用时通过远端列表选择。
3. 启用模型，回到聊天模型选择器选用，或设置为个人默认。

管理员已经开放的内置模型可直接使用。个人模型只使用个人 Key，清除后不可用，不会借用共享 Key。没有供应商时联系管理员添加，普通用户不能自定义供应商连接地址。

## 管理员

在模型页添加或编辑供应商，填写显示名、Base URL、API Key 和需要的模型列表端点。当前使用 OpenAI Completions API 兼容接口。保存供应商配置，添加并启用内置模型；供应商开关控制内置模型是否可用。

高级配置支持请求头 JSON、扩展请求体 JSON 和 API Key Env。请求头留空保留，填写 {} 清空。API Key Env 是管理员指定的共享凭据兜底，不用于创建模型；全局模型按个人 Key → 数据库共享 Key → 指定环境变量解析。环境变量变化需重启服务。普通用户的个人模型不使用这条兜底链。

## 常见问题

- 模型列表为空：先确认已配置供应商、模型和有效 Key，且启用状态正确。初始化只创建未启用且无凭据的供应商模板，不创建默认模型。
- 默认模型：可用的个人默认优先，然后内置默认，再由系统挑选可用模型；聊天里可以临时切换。
- 图片无法发送：当前模型必须显式支持图片；ZIP Skill 安装不需要视觉模型。
- 接口报错：请提供脱敏的状态码或错误提示，检查模型名、Base URL、Key 和供应商支持的能力。不要要求用户在聊天中粘贴 Key。

没有任何可用模型时，本教程也不能通过 AI 执行；先按界面的静态配置提示完成模型设置。
